7.1

Why U-Substitution Exists

The Chain Rule in Reverse

Recall from Section 03 that the chain rule says:

Chain Rule (differentiation)
ddx[F(g(x))] = F′(g(x)) · g′(x)

Reading that backwards — if we see a product of a composite function and the derivative of its inner part, we can integrate it:

Chain Rule Reversed (u-substitution)
∫ F′(g(x)) · g′(x) dx = F(g(x)) + C

Let u = g(x), then du = g′(x) dx:

∫ F′(u) du = F(u) + C → back-sub → F(g(x)) + C
🔁 U-sub is triggered by pattern recognition. You're looking for an integrand that looks like f(inner) × (derivative of inner). The inner function becomes u, and its derivative becomes du — making the integral clean.
The Pattern That Signals U-Sub
What to look for
∫ [some function of g(x)] · g′(x) dx

Example: ∫ sin(x²) · 2x dx
       inner = x²  |  derivative of inner = 2x ← it's right there!

Example: ∫ e3x+1 · 3 dx
       inner = 3x+1  |  derivative of inner = 3 ← it's right there!
7.2

The 6-Step Method

Apply in order every time
The Complete Procedure
  1. Identify u — the inner function. → Pick the expression whose derivative also appears in the integrand (or can be made to appear). Start with the most complex "inside" piece.
  2. Compute du/dx, then solve for dx. → Differentiate u with respect to x. Rearrange to get dx = du / (du/dx).
  3. Substitute u and dx into the integral — eliminate all x. → The entire integrand must be in terms of u only. If any x remains, u-sub won't work as chosen.
  4. Integrate with respect to u using basic rules. → The u-integral should now be a standard form — power rule, e^u, trig, etc.
  5. Back-substitute: replace u with the original expression in x. → The final answer must be in terms of x (for indefinite integrals).
  6. Add +C (for indefinite integrals only). → Never forget. This is the family of antiderivatives.
Fully Annotated Walkthrough
∫ 2x(x² + 1)⁵ dx — every step color coded
Choose u: u = x² + 1  (the inner function of the power)
Find du: du/dx = 2x  →  du = 2x dx
Substitute: ∫ u⁵ du  (2x and dx are both replaced by du)
Integrate: = u⁶6
Back-sub: = (x² + 1)⁶6
+C: = (x² + 1)⁶ / 6 + C
💡 Why did that work? The 2x in the integrand is exactly the derivative of x²+1. When the inner function's derivative is present in the integrand, u-sub will always clean up perfectly.

7.3

Adjusting When the Derivative Isn't Exact

Off by a constant factor
When du Doesn't Match Perfectly

Sometimes the derivative of u is in the integrand, but multiplied by the wrong constant. You can fix this by multiplying and dividing by the missing constant.

Example: ∫ x(x² + 1)⁴ dx
u = x² + 1  →  du = 2x dx  →  x dx = du/2

The integrand has x dx but du = 2x dx. So x dx = du/2.

∫ x·(x²+1)⁴ dx = ∫ u⁴ · du2 = 12∫ u⁴ du = u⁵10 = (x²+1)⁵10 + C
⚠️ You can only adjust for constants — not variable factors. If the missing piece is x² instead of 2, u-sub won't work with that choice of u. Constants can always be moved outside; variables cannot.
Practice · Adjusting for Missing Constants
Problem

→ Divide both sides of du = 4x³ dx by 4.

7.4

U-Substitution with Trig Functions

Trig of a Linear Function
Trigger: sin(ax+b), cos(ax+b), sec²(ax+b), etc.
u = ax+b  →  du = a dx  →  dx = du/a

∫ sin(3x) dx: u = 3x, du = 3dx, dx = du/3
= ∫ sin(u) · du/3 = (1/3)(−cos u) = −cos(3x)/3 + C

∫ cos(5x+2) dx: u = 5x+2, dx = du/5
= (1/5) sin(5x+2) + C
Trig Function Raised to a Power
Trigger: sinⁿx · cos x   or   cosⁿx · sin x
When trig is raised to a power and multiplied by its own derivative:

∫ sin⁴x · cos x dx:  u = sin x, du = cos x dx
= ∫ u⁴ du = u⁵/5 = sin⁵x / 5 + C

∫ cos³x · (−sin x) dx:  u = cos x, du = −sin x dx
= ∫ u³ du = u⁴/4 = cos⁴x / 4 + C
Trig Function Inside Another Function
Trigger: e^(sin x), ln(cos x), [tan x]ⁿ · sec²x
∫ e^(sin x) · cos x dx:  u = sin x, du = cos x dx
= ∫ e^u du = e^u = e^(sin x) + C

∫ tan⁵x · sec²x dx:  u = tan x, du = sec²x dx
= ∫ u⁵ du = u⁶/6 = tan⁶x / 6 + C

u = 4x+1  |  du = 4 dx  →  dx = du/4

(1/4) ∫ cos(u) du = (1/4) sin(u)

u = tan x  |  du = sec²x dx

∫ u² du = u³/3

= tan³x / 3 + C
7.5

U-Substitution with e^x and ln

e raised to a function
Trigger: e^(f(x)) · f′(x) — the exponent's derivative is present
∫ e^(x²) · 2x dx:  u = x², du = 2x dx
= ∫ e^u du = e^u = e^(x²) + C

∫ e^(3x+1) · 3 dx:  u = 3x+1, du = 3 dx
= ∫ e^u du = e^(3x+1) + C

∫ e^(sin x) · cos x dx:  u = sin x, du = cos x dx
= ∫ e^u du = e^(sin x) + C
1/f(x) · f′(x) — produces ln
Trigger: numerator is the derivative of the denominator
∫ 2xx² + 1 dx:  u = x²+1, du = 2x dx
= ∫ duu = ln|u| = ln|x²+1| + C

∫ cos xsin x dx:  u = sin x, du = cos x dx
= ∫ duu = ln|sin x| + C
💡 ln pattern recognition: Any time the numerator is (or is proportional to) the derivative of the denominator, the answer is ln|denominator| + C. This is the most common pattern on the AP exam for integrals that produce logarithms.

Numerator 3x² = derivative of denominator x³+5. This is the ∫ f′/f = ln|f| pattern.

u = x³ + 5  |  du = 3x² dx

∫ 3x² dxx³+5 = ∫ duu

Problem
Evaluate: ∫ x · e^(x²) dx
Step 1 — What is u? (the exponent)
Step 2 — Find du. Does x dx appear? Solve for x dx in terms of du.
Step 3 — Substitute and integrate ∫ e^u · du/constant
Step 4 — Back-substitute with +C
u = x²  |  du = 2x dx  →  x dx = du/2

(1/2) ∫ e^u du = (1/2) e^u

= e^(x²)/2 + C
Problem
Evaluate: ∫ sin x2 + cos x dx
Numerator sin x = −(derivative of denominator 2+cos x, since d/dx[cos x] = −sin x)

u = 2 + cos x  |  du = −sin x dx  →  sin x dx = −du

∫ −du/u = −ln|u|

= −ln|2 + cos x| + C
7.6

U-Substitution on Definite Integrals

Two methods — know both
Two Valid Methods
Method A — Change the Bounds (Cleaner)
When you substitute u = g(x), also convert the x-bounds to u-bounds using u = g(x).
Then you can evaluate directly without back-substituting.

Procedure:
Lower bound: substitute x = a into u = g(x) → u = g(a)
Upper bound: substitute x = b into u = g(x) → u = g(b)

Then evaluate ∫g(a)g(b) f(u) du directly.
Method B — Back-Substitute First
Treat the integral as indefinite, find F(u), back-substitute to F(g(x)), then evaluate at original x-bounds.

More steps, but avoids changing bounds. Both methods give the same answer.
Practice · Definite Integrals with U-Sub
Problem

1

2

When x = 0: u = 0² + 1 = 1
When x = 2: u = 4 + 1 = 5

7.7

When U-Sub Fails — and What to Try Instead

Signs That U-Sub Won't Work
IntegralWhy u-sub failsWhat to try
∫ x · e^x dx u = x → du = dx, but e^x isn't eliminated. u = e^x → du = e^x dx, but x isn't eliminated. Integration by parts (BC topic)
∫ x² sin x dx No choice of u eliminates all x variables. Integration by parts
∫ e^(x²) dx u = x², du = 2x dx — but there's no x in the integrand to supply the x in du. No closed form. Numerical methods only.
∫ sin²x dx No product structure — nothing to substitute. cos x not present. Trig identity: sin²x = (1−cos 2x)/2 → integrate directly.
∫ sec x dx No obvious inner/outer structure. Multiply by (sec x + tan x)/(sec x + tan x). Result: ln|sec x + tan x| + C
❌ The most common u-sub mistake: Choosing u and then having leftover x terms that can't be expressed in terms of u. This is the signal to try a different u or a different technique entirely.
