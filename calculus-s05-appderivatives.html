5.1

Critical Points & First Derivative Test

Definitions

Critical number: A value x = c in the domain of f where f′(c) = 0 or f′(c) is undefined.

Relative (local) maximum: f(c) ≥ f(x) for all x near c — a peak in the graph.

Relative (local) minimum: f(c) ≤ f(x) for all x near c — a valley in the graph.

⚠️ Critical numbers are candidates — not guarantees. Every local max/min must be at a critical number, but not every critical number is a local max or min (it could be neither — a flat point).
First Derivative Test — Procedure
  1. Find f′(x) and solve f′(x) = 0 and where f′ is undefined.→ These are the critical numbers.
  2. Place critical numbers on a number line. Pick a test value in each interval.→ The critical numbers divide the number line into intervals.
  3. Determine the sign of f′ in each interval.→ Positive f′ = increasing. Negative f′ = decreasing.
  4. Read the conclusion from the sign change.→ − to + = local min. + to − = local max. No change = neither.

Practice · First Derivative Test
Problem
Find all local maxima and minima of f(x) = x³ − 3x² − 9x + 5.
1
Find f′(x) and critical numbers
f′(x) = 3x² − 6x − 9 = 3(x² − 2x − 3) = 3(x − 3)(x + 1)
f′(x) = 0 → x = 3 and x = −1
2
Build the sign chart — test values in each interval
Intervals: (−∞,−1), (−1, 3), (3, ∞)

Test x = −2: f′(−2) = 3(−5)(−1) = +15 → positive ↗
Test x = 0: f′(0) = 3(−3)(1) = −9 → negative ↘
Test x = 4: f′(4) = 3(1)(5) = +15 → positive ↗
3
Read conclusions from sign changes
At x = −1: f′ goes + → −  →  local maximum
f(−1) = −1 − 3 + 9 + 5 = 10

At x = 3: f′ goes − → +  →  local minimum
f(3) = 27 − 27 − 27 + 5 = −22
Problem
Find all local extrema of g(x) = x³ − 12x.
Step 1 — Find g′(x) and solve g′(x) = 0
Step 2 — Set up your intervals and choose test values
Step 3 — Determine sign of g′ in each interval (+ or −)
Step 4 — State the local max/min with function values
g′(x) = 3x² − 12 = 3(x²−4) = 3(x−2)(x+2) → x = ±2

Test x = −3: g′ = 3(9)−12 = 15 → +
Test x = 0: g′ = −12 → −
Test x = 3: g′ = 27−12 = 15 → +

At x = −2: + → − → local max. g(−2) = −8 + 24 = 16
At x = 2: − → + → local min. g(2) = 8 − 24 = −16
Problem
Find all local extrema of h(x) = 2x³ + 3x² − 12x + 1.
h′(x) = 6x² + 6x − 12 = 6(x²+x−2) = 6(x+2)(x−1) → critical numbers: x = −2, x = 1

Test intervals: (−∞,−2): h′(−3) = 6(1)(−4) = +  |  (−2,1): h′(0) = −12 = −  |  (1,∞): h′(2) = 6(4)(1) = +

Local max at x = −2: h(−2) = −16 + 12 + 24 + 1 = 21
Local min at x = 1: h(1) = 2 + 3 − 12 + 1 = −6
5.2

Second Derivative Test, Concavity & Inflection Points

What f″ Tells You
f″(x) > 0
Concave up — the graph curves like a cup ∪
The slope f′ is increasing.
Tangent lines lie below the curve.
f″(x) < 0
Concave down — the graph curves like a cap ∩
The slope f′ is decreasing.
Tangent lines lie above the curve.
Inflection Points

An inflection point is where concavity changes — from up to down or down to up. To find them:

  1. Find f″(x) and set it equal to zero (or find where it's undefined).
  2. Test the sign of f″ on either side.→ If f″ changes sign, it's an inflection point. If it doesn't change sign, it's NOT an inflection point.
  3. State the inflection point as (x, f(x)) — both coordinates.
❌ f″(c) = 0 does NOT guarantee an inflection point. Example: f(x) = x⁴ has f″(0) = 0, but f″ doesn't change sign at 0 — no inflection point. You must verify the sign change.
Second Derivative Test for Local Extrema

Faster than the first derivative test — but it can fail.

Second Derivative Test
At a critical number c where f′(c) = 0:

If f″(c) > 0 → concave up at c → local minimum
If f″(c) < 0 → concave down at c → local maximum
If f″(c) = 0 → test is inconclusive — use first derivative test instead
💡 Memory: Positive second derivative = concave UP = minimum (bottom of the cup). Negative = concave DOWN = maximum (top of the hill).
Practice · Concavity, Inflection & 2nd Deriv Test
Problem
For f(x) = x⁴ − 4x³, find: (a) intervals of concavity, (b) inflection points, (c) classify critical points using the 2nd derivative test.
1
Find f′ and critical numbers
f′(x) = 4x³ − 12x² = 4x²(x − 3)
f′ = 0 → x = 0 and x = 3
2
Find f″ and solve f″ = 0
f″(x) = 12x² − 24x = 12x(x − 2)
f″ = 0 → x = 0 and x = 2
3
Sign chart for f″ — concavity intervals
Test x = −1: f″(−1) = 12(−1)(−3) = 36 → +, concave up
Test x = 1: f″(1) = 12(1)(−1) = −12 → −, concave down
Test x = 3: f″(3) = 12(3)(1) = 36 → +, concave up

Concave up: (−∞, 0) ∪ (2, ∞)  |  Concave down: (0, 2)
4
Identify inflection points — check sign change
At x = 0: f″ goes + → − → sign changes → inflection point
f(0) = 0 → inflection point: (0, 0)

At x = 2: f″ goes − → + → sign changes → inflection point
f(2) = 16 − 32 = −16 → inflection point: (2, −16)
5
Apply 2nd derivative test at critical numbers
At x = 0: f″(0) = 0 → inconclusive (use 1st derivative test: f′ doesn't change sign → neither max nor min)
At x = 3: f″(3) = 36 > 0 → local minimum
f(3) = 81 − 108 = −27 → local min at (3, −27)
Problem
For g(x) = x³ − 6x² + 9x, find intervals of concavity and all inflection points.
Step 1 — Find g″(x)
Step 2 — Solve g″(x) = 0
Step 3 — Test sign of g″ on each interval
Step 4 — State concavity intervals and inflection point(s) with coordinates
g′(x) = 3x²−12x+9  |  g″(x) = 6x−12
g″ = 0 → 6x = 12 → x = 2

Test x = 0: g″(0) = −12 → concave down
Test x = 3: g″(3) = 6 → concave up

Concave down: (−∞, 2)  |  Concave up: (2, ∞)
g(2) = 8−24+18 = 2
Inflection point: (2, 2)
Problem
For h(x) = x⁴ − 8x², find all inflection points and classify the critical points using the second derivative test.
h′(x) = 4x³−16x = 4x(x²−4) = 4x(x−2)(x+2) → critical: x = 0, ±2
h″(x) = 12x²−16

At x = 0: h″(0) = −16 < 0 → local max. h(0) = 0
At x = 2: h″(2) = 48−16 = 32 > 0 → local min. h(2) = 16−32 = −16
At x = −2: h″(−2) = 32 > 0 → local min. h(−2) = −16

Inflection: h″ = 0 → x = ±2/√3 = ±√3·2/3
h″ changes sign at each → inflection points at x = ±2√3/3
5.3

Optimization

Maximization & Minimization
The 5-Step Process
  1. Draw and label a diagram.→ Identify the quantity to optimize and all related quantities.
  2. Write the objective function — the formula for what you're maximizing or minimizing.→ This is the function you'll differentiate.
  3. Write the constraint equation — the relationship between variables.→ Use it to eliminate one variable so you have one equation in one unknown.
  4. Differentiate, set equal to zero, solve for the critical number.→ Apply first or second derivative test to confirm it's a max or min.
  5. Answer the question in context.→ Re-read the problem. Give units. State whether it's a max or min.
❌ Most common error: Plugging in constraint values before differentiating. Always get to one variable first, then differentiate. Plugging in too early destroys the function you need to optimize.
Practice · Optimization
Problem
A farmer has 200 meters of fence to enclose a rectangular field. Find the dimensions that maximize the area.
1
Define variables
Let x = width, y = length of the rectangle.
2
Write the objective function
Area: A = x · y  ← this is what we maximize.
3
Write the constraint equation
Perimeter: 2x + 2y = 200 → y = 100 − x
4
Substitute constraint into objective, then differentiate
A = x(100 − x) = 100x − x²
A′ = 100 − 2x = 0 → x = 50
A″ = −2 < 0 → confirms maximum ✓
5
Find both dimensions and state the answer
x = 50m, y = 100 − 50 = 50m
A square field, 50m × 50m, gives maximum area of 2500 m².
→ Among all rectangles with fixed perimeter, the square always has maximum area.
Problem
Find two positive numbers whose sum is 60 and whose product is maximized.
Step 1 — Let the two numbers be x and y. Write the constraint (their sum = 60)
Step 2 — Write the objective function P = x · y, then substitute constraint
Step 3 — Differentiate P, set P′ = 0, solve for x
Step 4 — Find y, verify it's a maximum (check P″ or sign chart), state the answer
y = 60 − x
P = x(60−x) = 60x − x²
P′ = 60 − 2x = 0 → x = 30
P″ = −2 < 0 → maximum ✓
y = 60 − 30 = 30
The two numbers are 30 and 30. Maximum product = 900.
Problem
A box with a square base and no top is to be made from 48 m² of material. Find the dimensions that maximize its volume.
Let x = side of square base, h = height.
Surface area (no top): x² + 4xh = 48 → h = (48−x²)/(4x)
Volume: V = x²h = x² · (48−x²)/(4x) = (48x − x³)/4
V′ = (48 − 3x²)/4 = 0 → 3x² = 48 → x² = 16 → x = 4
h = (48−16)/16 = 2
V″ = −6x/4 < 0 at x = 4 → maximum ✓
Base = 4m × 4m, height = 2m, max volume = 32 m³
5.4

Related Rates

What Related Rates Problems Are

Related rates problems give you how fast one quantity is changing and ask you to find how fast a related quantity is changing. Both are changing with respect to time t. The key is to differentiate an equation relating the quantities implicitly with respect to t.

The 5-Step Process
  1. Draw and label a diagram with all variables that change with time.→ Do NOT plug in values that are changing yet — keep them as variables.
  2. Write an equation relating the variables.→ This is the geometric or physical relationship: Pythagorean theorem, area formula, volume formula, similar triangles, etc.
  3. Differentiate both sides with respect to t (implicit differentiation).→ Every variable gets a d/dt. This is where dx/dt, dy/dt, etc. appear.
  4. Substitute known values — including given rates.→ ONLY after differentiating. Plugging in before differentiating is the #1 error.
  5. Solve for the unknown rate. Give units and direction.
❌ #1 Error — plugging in too early: If a side length is "currently 5m," that value goes in AFTER differentiating, not before. The equation must be differentiated while variables are still general.
Practice · Related Rates
Problem
A ladder 10m long leans against a vertical wall. The base slides away at 2 m/s. How fast is the top sliding down when the base is 6m from the wall?
1
Label variables
Let x = distance of base from wall, y = height of top on wall.
Given: dx/dt = +2 m/s  |  Find: dy/dt when x = 6
2
Write the relating equation
Pythagorean theorem: x² + y² = 100
→ The ladder is always 10m, so the hypotenuse is constant at 10.
3
Differentiate with respect to t
2x·dx/dt + 2y·dy/dt = 0
→ The 100 differentiates to 0 (constant). Both x and y get d/dt multiplied in.
4
Find y when x = 6, then substitute all known values
x = 6: y = √(100−36) = √64 = 8
2(6)(2) + 2(8)·dy/dt = 0
24 + 16·dy/dt = 0
5
Solve for dy/dt
dy/dt = −24/16 = −3/2 m/s
→ Negative means the top is moving downward. Always interpret the sign.
Problem
A spherical balloon is being inflated. Its radius increases at 3 cm/s. How fast is the volume increasing when radius = 5 cm? (V = 4/3 πr³)
Step 1 — Identify the variable, given rate, and what you're finding
Step 2 — Write the equation relating V and r
Step 3 — Differentiate both sides with respect to t
Step 4 — Substitute r = 5 and dr/dt = 3
V = (4/3)πr³
dV/dt = 4πr² · dr/dt
At r = 5, dr/dt = 3:
dV/dt = 4π(25)(3) = 300π cm³/s
Problem
Water drains from a conical tank (radius 4m, height 8m) at 2 m³/min. How fast is the water level dropping when the depth is 3m? (V = πr²h/3. Use similar triangles: r/h = 4/8 = 1/2.)
Similar triangles: r = h/2
V = (1/3)π(h/2)²h = πh³/12
dV/dt = (π/12)·3h²·dh/dt = πh²/4 · dh/dt
Given dV/dt = −2 (draining), h = 3:
−2 = π(9)/4 · dh/dt
dh/dt = −8/(9π) m/min
The water level drops at 8/(9π) ≈ 0.283 m/min.

L'Hôpital's Rule

When It Applies

L'Hôpital's Rule applies when direct substitution gives an indeterminate form:

Indeterminate forms where L'Hôpital applies
0/0    or    ∞/∞

Other forms (0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰) must be algebraically converted to 0/0 or ∞/∞ first.
The Rule
If lim f(x)/g(x) gives 0/0 or ∞/∞, then:

limx→a f(x)g(x) = limx→a f′(x)g′(x)

Differentiate the numerator and denominator separately — this is NOT the quotient rule.
❌ Critical distinction: L'Hôpital's Rule is NOT the quotient rule. You differentiate f and g independently. d/dx[f/g] ≠ f′/g′ in general — but L'Hôpital says the LIMIT of f/g equals the LIMIT of f′/g′ under those specific conditions.
When to Apply Repeatedly

If applying L'Hôpital once still gives 0/0 or ∞/∞, apply it again. Keep going until you get a determinate form or can evaluate directly.

Example — Apply Twice
limx→0 1 − cos xx²   →   0/0  →  apply L'H:

= lim sin x2x   →   0/0 again  →  apply L'H again:

= lim cos x2 = cos(0)/2 = 1/2
Practice · L'Hôpital's Rule
Problem
Evaluate: limx→0 sin xx
1
Confirm the indeterminate form
Direct substitution: sin(0)/0 = 0/0 ✓   L'Hôpital applies.
2
Differentiate numerator and denominator separately
d/dx[sin x] = cos x    d/dx[x] = 1
→ These are independent derivatives, NOT the quotient rule.
3
Evaluate the new limit
limx→0 cos x / 1 = cos(0) / 1 = 1
Problem
Evaluate: limx→1 x³ − 1x − 1
Step 1 — Check direct substitution. What form do you get?
Step 2 — Differentiate numerator and denominator separately
Step 3 — Evaluate the new limit at x = 1
Sub x = 1: 0/0 → L'Hôpital applies ✓
d/dx[x³−1] = 3x²  |  d/dx[x−1] = 1
limx→1 3x²/1 = 3

(Verify: factor method gives (x−1)(x²+x+1)/(x−1) = x²+x+1 → at x=1: 3 ✓)
Problem
Evaluate: limx→∞ ln xx
As x→∞: ln x → ∞, x → ∞ → form: ∞/∞ → L'Hôpital applies ✓

d/dx[ln x] = 1/x  |  d/dx[x] = 1
limx→∞ (1/x)/1 = limx→∞ 1/x = 0

ln x grows much slower than x — this confirms it.

Slope Fields

What a Slope Field Is

A slope field (direction field) is a visual representation of a differential equation dy/dx = f(x, y). At each point (x, y) in the plane, a short line segment is drawn with slope equal to f(x, y). The collection of these segments shows the "flow" of solutions.

A solution curve drawn through the slope field will always be tangent to the segments it passes through.

How to Draw a Slope Field
  1. Pick a grid of points (x, y).
  2. Plug each point into dy/dx = f(x,y) to get the slope at that point.
  3. Draw a short segment with that slope at each point.→ Positive slope: /   Negative slope: \   Zero slope: —   Undefined: |
Reading a Slope Field — AP FRQ Skills
Key Observations
Horizontal segments (slope = 0): These form the isocline f(x,y) = 0. The solution has a horizontal tangent here — it's a potential max/min of the solution.

Vertical segments (slope undefined): Occurs when the denominator of dy/dx = 0. Vertical tangent to solution curve.

Uniform rows/columns: If slopes depend only on x (not y), entire columns have the same slope. If only on y, entire rows match.
💡 AP FRQ tip: When sketching a solution curve, your pencil must follow the local slope at every point. Never cross a segment at the wrong angle — graders check that your curve is tangent to the field.
Example Slope Field — dy/dx = x
Blue = negative slope (left side x<0) · Green = zero slope (x=0 column) · Gold = positive slope (right side x>0) · Purple dashed = solution curve y = x²/2 + C
Practice · Slope Fields
Problem
For dy/dx = y, describe what the slope field looks like and what the solution curves are.
1
Evaluate dy/dx at key points
At any point where y = 0: slope = 0 → horizontal segments along the x-axis
Where y > 0: slope > 0 → segments slope upward
Where y < 0: slope < 0 → segments slope downward
The slope depends only on y — not x. So every horizontal row has the same slope.
2
Identify the solution curves
dy/dx = y is a separable differential equation. Solving: dy/y = dx → ln|y| = x + C → y = Ae^x for any constant A.
→ All solution curves are exponential. The slope field "flows" like exponential growth above the x-axis and decay below it.
3
Sketch description for FRQ
A solution curve through (0, 1) follows y = e^x. Through (0, −1): y = −e^x. The x-axis itself (y = 0, A = 0) is a solution — a horizontal line.
Problem
For dy/dx = −x/y, compute the slope at (1,2), (−1,1), (2,0), and (0,3). What shape do the solution curves make?
Evaluate dy/dx at each point
What happens at y = 0? What does that mean geometrically?
Separate variables and solve the DE: −x/y dy = dx (hint: what familiar curve satisfies x² + y² = C?)
(1,2): −1/2  |  (−1,1): 1/1 = 1  |  (2,0): −2/0 = undefined (vertical tangent)  |  (0,3): 0/3 = 0 (horizontal)

At y = 0: slope undefined → vertical tangents on the x-axis.

Separating: y dy = −x dx → y²/2 = −x²/2 + C → x² + y² = C
Solution curves are circles centered at the origin.
Problem
dy/dx = 2x − 1. (a) Find all points where segments are horizontal. (b) Describe how slopes change as x increases. (c) Sketch the solution curve through (0, 2).
(a) Horizontal where 2x − 1 = 0 → x = 1/2. The entire vertical line x = 1/2 has horizontal segments.

(b) As x increases from left to right, slopes go from very negative (x→−∞) through 0 at x = 1/2 to very positive (x→∞). Slope is independent of y — same in every row.

(c) Solve: dy/dx = 2x−1 → y = x² − x + C. Plug in (0,2): 2 = 0 − 0 + C → C = 2.
Solution curve through (0,2): y = x² − x + 2 (upward-opening parabola with vertex at x = 1/2)
