The one question that shows up every year: when do you use sin vs cos for position? This section answers it completely — with the starting condition logic, the full position-velocity-acceleration chain, phase shifts, and every problem type you'll see.

13.1

What Simple Harmonic Motion Is

The Setup

Simple harmonic motion (SHM) describes any object that oscillates back and forth around an equilibrium position — a spring-mass system, a pendulum (small angles), a buoy bobbing in water. The position repeats in a perfect sine or cosine wave.

The general position function is:

General SHM Position Function
x(t) = A · trig(ωt + φ)

A = amplitude (maximum displacement from equilibrium)
ω = angular frequency (how fast it oscillates), ω = 2π/T
T = period (time for one complete cycle)
φ = phase shift (horizontal shift — determined by starting condition)
trig = either sin or cos — determined by the initial position

13.2

Sin vs Cos — The Decision You Must Get Right

The Rule — Based on Starting Position

The choice between sin and cos depends entirely on where the object is at t = 0. This is the initial condition, and it uniquely determines which trig function to use.

x(t) = A cos(ωt)
Use Cosine When...
Object starts at maximum displacement
x(0) = A (at the peak, fully stretched/compressed)
cos(0) = 1 → x(0) = A ✓
Examples:
Spring stretched to maximum and released. Pendulum released from maximum angle. Object at top of a wave at t=0.
Velocity at t=0:
v(0) = −Aω sin(0) = 0
Object is momentarily at rest at maximum displacement. Makes physical sense.
x(t) = A sin(ωt)
Use Sine When...
Object starts at equilibrium
x(0) = 0 (at rest position, moving)
sin(0) = 0 → x(0) = 0 ✓
Examples:
Object at rest position pushed into motion. Pendulum released from center. Object at zero displacement moving upward at t=0.
Velocity at t=0:
v(0) = Aω cos(0) = Aω
Object has maximum velocity at equilibrium. Makes physical sense.
💡 Memory shortcut: Cosine → Crest (starts at maximum). Sine → Start at zero (starts at equilibrium). Both start with C and S respectively.
⚠️ What if it starts at a negative displacement? Use x(t) = −A cos(ωt) if released from the negative maximum. The negative sign flips the starting position. x(0) = −A(1) = −A ✓
Blue solid = cosine (starts at maximum A). Orange dashed = sine (starts at equilibrium 0). Both have the same amplitude and period — only the starting position differs.

Problem
A spring-mass system oscillates with amplitude 0.3 m and period 2 seconds. At t=0 the mass is at maximum displacement (0.3 m from equilibrium). Write x(t).
1
Identify the starting condition
At t=0: x(0) = 0.3 m = A (maximum displacement). → Use cosine.
→ cos(0) = 1, so A·cos(0) = A. This gives x(0) = A automatically.
2
Find ω from the period
ω = 2π/T = 2π/2 = π rad/s
3
Write the position function
x(t) = 0.3 cos(πt) meters
4
Verify: check x(0)
x(0) = 0.3 cos(0) = 0.3(1) = 0.3 m ✓

13.3

Position → Velocity → Acceleration

Differentiation Chain

In SHM, position x(t), velocity v(t), and acceleration a(t) are all connected by differentiation. Each one is the derivative of the previous.

Starting with x(t) = A cos(ωt)
x(t) = A cos(ωt)     ← position
v(t) = x′(t) = −Aω sin(ωt)   ← velocity (chain rule: multiply by ω)
a(t) = v′(t) = −Aω² cos(ωt)  ← acceleration

Notice: a(t) = −ω² x(t) — acceleration is always proportional to negative position. This is the defining equation of SHM.
Starting with x(t) = A sin(ωt)
x(t) = A sin(ωt)     ← position
v(t) = x′(t) = Aω cos(ωt)   ← velocity
a(t) = v′(t) = −Aω² sin(ωt)  ← acceleration

Again: a(t) = −ω² x(t)
Maximum Values — When Each Is Greatest
QuantityMaximum ValueOccurs WhenPhysical Meaning
|x(t)|A (amplitude)cos or sin = ±1At the turning points — max stretch/compression
|v(t)|AωAt x = 0 (equilibrium)Maximum speed occurs as it passes through center
|a(t)|Aω²At x = ±A (max displacement)Maximum restoring force at turning points
💡 Pattern: Position and acceleration are maximized at the same time (at the endpoints). Velocity is maximized when position = 0 (at equilibrium). Speed and position trade off — when one is max, the other is zero.
Phase Relationships — How They're Shifted
Phase Shift Pattern (starting from cosine)
x(t) = A cos(ωt)           ← reference
v(t) = −Aω sin(ωt) = Aω cos(ωt + π/2)  ← leads x by π/2
a(t) = −Aω² cos(ωt) = Aω² cos(ωt + π)  ← opposite phase to x

v is 90° ahead of x.   a is 180° ahead of x (exactly opposite).
Practice · Position, Velocity, Acceleration
Problem
A mass oscillates with x(t) = 4 cos(3t) cm. Find v(t), a(t), the maximum speed, and the maximum acceleration.
1
Find v(t) — differentiate x(t)
v(t) = x′(t) = 4 · (−sin(3t)) · 3 = −12 sin(3t) cm/s
→ Chain rule: d/dt[cos(3t)] = −sin(3t) · 3. The 3 (= ω) multiplies in.
2
Find a(t) — differentiate v(t)
a(t) = v′(t) = −12 · cos(3t) · 3 = −36 cos(3t) cm/s²
→ d/dt[−12 sin(3t)] = −12 cos(3t) · 3. Note a(t) = −9 x(t) = −ω² x(t) ✓
3
Maximum speed and acceleration
|v|max = Aω = 4(3) = 12 cm/s (when sin = ±1, i.e., at equilibrium)
|a|max = Aω² = 4(9) = 36 cm/s² (when cos = ±1, i.e., at max displacement)
Problem
x(t) = 0.5 sin(2πt) m. Find v(t), a(t), and the time(s) when the object is moving fastest on [0, 1].
Step 1 — Find v(t) = x′(t) using chain rule
Step 2 — Find a(t) = v′(t)
Step 3 — When is |v(t)| maximum? (when is |cos(2πt)| = 1?)
v(t) = 0.5 · cos(2πt) · 2π = π cos(2πt) m/s
a(t) = π · (−sin(2πt)) · 2π = −2π² sin(2πt) m/s²

Max speed when |cos(2πt)| = 1:
2πt = 0, π, 2π → t = 0, 1/2, 1
Object moves fastest at t = 0, 1/2, and 1 s (at equilibrium positions)
Maximum speed = π ≈ 3.14 m/s
Problem
A buoy bobs with position x(t) = 2 cos(πt/3) feet (t in seconds). Find: (a) v(t) and a(t). (b) When is the buoy at equilibrium on [0, 6]? (c) What is the maximum speed?
(a) v(t) = −2·sin(πt/3)·(π/3) = −(2π/3)sin(πt/3) ft/s
a(t) = −(2π/3)·cos(πt/3)·(π/3) = −(2π²/9)cos(πt/3) ft/s²

(b) At equilibrium: x(t) = 0 → cos(πt/3) = 0 → πt/3 = π/2, 3π/2 → t = 3/2, 9/2 seconds

(c) Max speed = Aω = 2·(π/3) = 2π/3 ≈ 2.09 ft/s
13.4

Phase Shifts & General Form

When the Initial Condition Is Neither Max Nor Zero

If the object starts at a position other than ±A or 0, the general form with a phase shift φ is needed:

General Form with Phase Shift
x(t) = A cos(ωt + φ)

To find φ: use x(0) = A cos(φ) and v(0) = −Aω sin(φ)

Step 1: Solve cos(φ) = x(0)/A
Step 2: Check sign of v(0) to determine which quadrant φ is in
ℹ️ In most AP and physics problems, the initial condition will be either x(0) = A (use cosine) or x(0) = 0 (use sine), so you rarely need the full phase shift formula. But you should know it exists for the case where neither applies.
Complete Step-by-Step — Given Any Initial Condition
  1. Read x(0) from the problem.→ This is where the object is when the clock starts.
  2. Read v(0) from the problem (or infer: at rest = 0, moving = ±value).
  3. If x(0) = A and v(0) = 0: use x(t) = A cos(ωt)→ Starts at max, at rest.
  4. If x(0) = 0 and v(0) = Aω (positive): use x(t) = A sin(ωt)→ Starts at equilibrium, moving positive.
  5. If x(0) = 0 and v(0) = −Aω (negative): use x(t) = −A sin(ωt)→ Starts at equilibrium, moving negative direction.
  6. If x(0) = −A and v(0) = 0: use x(t) = −A cos(ωt)→ Starts at negative max, at rest.
Practice · Full SHM Problems
Full SHM Problem
A spring-mass system has period T = π seconds and amplitude A = 6 cm. At t = 0 the mass is at the equilibrium position and moving in the negative direction. Find x(t), v(t), and a(t). Then find the first time t > 0 when the mass is at maximum positive displacement.
1
Determine sin or cos from initial condition
x(0) = 0 (equilibrium) → use sine.
v(0) < 0 (moving negative) → use −sin: x(t) = −6 sin(ωt)
→ x(t) = A sin(ωt) gives v(0) = Aω (positive). We need negative, so negate: x(t) = −6 sin(ωt).
2
Find ω
ω = 2π/T = 2π/π = 2 rad/s
3
Write all three functions
x(t) = −6 sin(2t) cm
v(t) = −6·2·cos(2t) = −12 cos(2t) cm/s
a(t) = −12·(−2)·sin(2t) = 24 sin(2t) cm/s²
4
Find first time at maximum positive displacement (x = +6)
x(t) = +6 → −6 sin(2t) = 6 → sin(2t) = −1
2t = 3π/2 → t = 3π/4 seconds

A pendulum oscillates with amplitude 0.4 m and frequency f = 0.5 Hz. At t=0 it is at maximum positive displacement. Write x(t), find v(t) and a(t), and determine when it first reaches equilibrium.
Step 1 — x(0) = A (max positive) → sin or cos? Find ω from f.
Step 2 — Write x(t), then differentiate to get v(t) and a(t)
Step 3 — Find the first t > 0 when x(t) = 0
x(0) = A → use cosine. ω = 2π(0.5) = π rad/s

x(t) = 0.4 cos(πt) m
v(t) = −0.4π sin(πt) m/s
a(t) = −0.4π² cos(πt) m/s²

Challenge Problem
A mass on a spring has A = 3 cm, T = 2π s. At t = 0 it passes through equilibrium moving in the positive direction. (a) Write x(t). (b) Find the first t > 0 when speed is maximum and state the speed. (c) Find the first t > 0 when acceleration is maximum magnitude and state the acceleration. (d) Show that a(t) = −x(t).
(a) x(0) = 0, v(0) > 0 → use sin. ω = 2π/2π = 1 rad/s
x(t) = 3 sin(t) cm

(b) Max speed when |cos(t)| = 1 → t = 0, π, 2π... First t > 0: t = π s
v(t) = 3 cos(t) → max speed = 3 cm/s

(c) a(t) = −3 sin(t). Max |a| when |sin(t)| = 1 → t = π/2, 3π/2...
First t > 0: t = π/2 s. Max acceleration = 3 cm/s²

(d) a(t) = v′(t) = [3cos(t)]′ = −3 sin(t) = −x(t) ✓
Since ω = 1: a(t) = −ω²x(t) = −(1)²x(t) = −x(t) ✓
13.5

Connecting SHM Back to Calculus

Everything in SHM Uses Calculus

SHM is a perfect application of everything in this guide:

SHM is Calculus
Chain rule: differentiating A cos(ωt) → −Aω sin(ωt) uses the chain rule (inner = ωt, outer = cos)

FTC Part 2: displacement = ∫ab v(t) dt = x(b) − x(a)

Total distance: ∫ab |v(t)| dt (split at zeros of v)

Antidifferentiation: ∫v(t) dt = x(t) + C (recover position from velocity)

Critical points: speed = 0 when object changes direction → local extrema of x(t)
The Defining Equation of SHM — Why It's Called Harmonic

The equation a = −ω²x is what defines simple harmonic motion. It says acceleration is always directed toward equilibrium and proportional to displacement — the restoring force. Substituting x(t) = A cos(ωt) proves it satisfies this equation:

SHM Differential Equation
x″(t) = −ω² x(t)

Verify: x(t) = A cos(ωt)
x′(t) = −Aω sin(ωt)
x″(t) = −Aω² cos(ωt) = −ω² [A cos(ωt)] = −ω² x(t) ✓

Both A cos(ωt) and A sin(ωt) satisfy this equation. Initial conditions determine which.
Practice · SHM + Calculus Applications
Problem
A particle moves with v(t) = 4 cos(2t) cm/s and x(0) = 3 cm. Find x(t). Also find the total distance traveled from t = 0 to t = π.
1
Find x(t) by antidifferentiating v(t)
x(t) = ∫ 4 cos(2t) dt = 4 · sin(2t)2 + C = 2 sin(2t) + C
→ u-sub: u = 2t, du = 2dt. ∫cos(u)(du/2) = (1/2)sin(u).
2
Apply initial condition x(0) = 3 to find C
3 = 2 sin(0) + C = 0 + C → C = 3
x(t) = 2 sin(2t) + 3 cm
3
Total distance — find zeros of v on [0, π]
v(t) = 0: cos(2t) = 0 → 2t = π/2, 3π/2 → t = π/4, 3π/4
On [0, π/4]: v > 0. On [π/4, 3π/4]: v < 0. On [3π/4, π]: v > 0.
4
Integrate each piece with absolute value
Distance = ∫0π/44cos(2t)dt + |∫π/43π/44cos(2t)dt| + ∫3π/4π4cos(2t)dt
= [2sin(2t)]0π/4 + |[2sin(2t)]π/43π/4| + [2sin(2t)]3π/4π
= 2 + |−4| + 2 = 8 cm

A mass has velocity v(t) = −6 sin(3t) cm/s and starts at x(0) = 2 cm. Find x(t) and verify it represents SHM by showing x″ = −9x.
Step 1 — Antidifferentiate v(t) = −6 sin(3t) to find x(t) + C
Step 2 — Apply x(0) = 2 to find C
Step 3 — Find x″(t) and verify x″ = −9x
∫−6sin(3t)dt = −6·(−cos(3t)/3) + C = 2cos(3t) + C
x(0) = 2cos(0) + C = 2 + C = 2 → C = 0

x′(t) = −6sin(3t) = v(t) ✓
x″(t) = −18cos(3t)
−9x(t) = −9(2cos(3t)) = −18cos(3t) = x″(t) ✓
Problem
x(t) = 5 sin(πt) cm. Find: (a) displacement from t=0 to t=2. (b) total distance from t=0 to t=2. (c) average position from t=0 to t=2.
(a) Displacement = ∫02 v(t) dt = ∫02 5π cos(πt) dt = [5sin(πt)]02 = 5sin(2π) − 5sin(0) = 0 cm
(Returns to starting position after one full period T = 2.)

(b) v(t) = 5π cos(πt) = 0 at t = 1/2, 3/2. Split:
[0, 1/2]: v > 0, [1/2, 3/2]: v < 0, [3/2, 2]: v > 0
Each quarter period: distance = 5 cm (amplitude)
Total distance = 4 × 5 = 20 cm

(c) Average position = (1/2)∫02 5sin(πt) dt = (1/2)[−5cos(πt)/π]02 = (1/2)(−5/π)(cos(2π)−cos(0)) = (1/2)(−5/π)(0) = 0 cm
(The average position over a full period is always 0 — symmetric oscillation.)
