Section 04 · AP Calculus AB

Implicit
Differentiation

How to differentiate equations where y can't easily be isolated — including tricky mixed terms, products of x and y, tangent lines, and second derivatives. Every step annotated so you see exactly where dy/dx comes from.

4.1

What It Is & When To Use It

The Problem

Explicit differentiation works when you have y = f(x) — y is alone on one side. But some equations mix x and y together in ways that can't easily be untangled:

Examples Where You Cannot Isolate y Cleanly
x² + y² = 25  (circle)    |    x³ + y³ = 6xy  (folium of Descartes)
sin(y) + x²y = 4    |    e^y + xy² = 8

For these, we differentiate both sides with respect to x, treating y as a function of x. Every time we differentiate a term with y, we apply the chain rule — which introduces dy/dx.

Explicit vs Implicit — Side by Side
Explicit
y = x³ + 2x

d/dx[y] = d/dx[x³ + 2x]

dy/dx = 3x² + 2
Implicit
x³ + y³ = 5

d/dx[x³] + d/dx[y³] = d/dx[5]

3x² + 3y²·dy/dx = 0
ℹ️ Why does dy/dx appear? Because d/dx[y³] uses the chain rule: the outer function is u³, the inner function is y. So it becomes 3y² · (dy/dx). The chain rule always introduces dy/dx when differentiating any term containing y.
4.2

The Step-by-Step Procedure

The 4-Step Method
  1. Differentiate both sides of the equation with respect to x. → Every term gets differentiated. Left side = right side at every step — never drop one side.
  2. Every time you differentiate a y-term, attach · dy/dx (chain rule). → This is the entire mechanic of implicit differentiation. y is a function of x, so chain rule always applies to it.
  3. Collect all dy/dx terms on one side, all other terms on the other side. → Move every term with dy/dx to the left, everything else to the right (or vice versa).
  4. Factor out dy/dx, then divide to isolate it. → If multiple terms have dy/dx, factor it out first: dy/dx·(___) = ___, then divide.
Annotated Walkthrough — x² + y² = 25
The Work
1
x² + y² = 25
2
2x + 2y·dy/dx = 0
3
2y·dy/dx = −2x
4
dy/dx = −xy
Why Each Step
1
Original equation
2
d/dx[x²] = 2x. d/dx[y²] = 2y·dy/dx (chain rule). d/dx[25] = 0.
3
Move 2x to the right side.
4
Divide both sides by 2y. The 2s cancel.
💡 Key insight: dy/dx = −x/y means the slope of the tangent at any point (x, y) on the circle is −x/y. To get a number, you plug in the specific point. The answer staying in terms of both x and y is normal and expected.
Practice · Basic Implicit Differentiation
Problem
Find dy/dx for:   x³ + y³ = 6xy
1
Differentiate both sides with respect to x
Left side has two terms. Right side is a product of 6, x, and y — needs product rule.

d/dx[x³] + d/dx[y³] = d/dx[6xy]
2
Differentiate each piece
d/dx[x³] = 3x²
d/dx[y³] = 3y²·dy/dx  (chain rule)
d/dx[6xy] = 6[1·y + x·dy/dx] = 6y + 6x·dy/dx  (product rule on x·y)
→ 6xy is a product: f = x, g = y. Product rule: f′g + fg′ = (1)y + x·(dy/dx).
3
Write the full differentiated equation
3x² + 3y²·dy/dx = 6y + 6x·dy/dx
4
Collect dy/dx terms on one side
3y²·dy/dx − 6x·dy/dx = 6y − 3x²
dy/dx(3y² − 6x) = 6y − 3x²
5
Divide to isolate dy/dx
dy/dx = 6y − 3x²3y² − 6x = 2y − x²y² − 2x
→ Factor 3 from numerator and denominator to simplify.
Problem
Find dy/dx for:   x² + 3y² = 10
Step 1 — Differentiate both sides with respect to x
Step 2 — Remember: d/dx[3y²] needs the chain rule. What do you get?
Step 3 — Move terms without dy/dx to the right side
Step 4 — Divide to isolate dy/dx
d/dx[x²] = 2x  |  d/dx[3y²] = 6y·dy/dx  |  d/dx[10] = 0

2x + 6y·dy/dx = 0
6y·dy/dx = −2x

dy/dx = −x / (3y)
Problem
Find dy/dx for:   4x² − y² = 16
Differentiate: 8x − 2y·dy/dx = 0
−2y·dy/dx = −8x

dy/dx = 4x / y
4.3

Tricky Cases

Products · Trig · e^y · Higher powers
Case 1 — Product of x and y (Most Common Trap)

When a term contains both x and y multiplied together, you must use the product rule AND attach dy/dx to the y part.

Pattern: d/dx[ x · y ]
d/dx[x · y] = (1)·y + x·dy/dx = y + x·dy/dx

d/dx[x² · y] = 2x·y + x²·dy/dx

d/dx[x · y³] = (1)·y³ + x·3y²·dy/dx = y³ + 3xy²·dy/dx
❌ Most missed step: Students differentiate x·y as just y or just x·dy/dx — both wrong. It's a product. Both f′g and fg′ terms must appear.
Case 2 — Trig Functions of y
Pattern: d/dx[ trig(y) ]
d/dx[sin y] = cos y · dy/dx
d/dx[cos y] = −sin y · dy/dx
d/dx[tan y] = sec²y · dy/dx

Rule: differentiate the trig function normally, then multiply by dy/dx (chain rule on y).
Case 3 — e^y and ln(y)
Pattern: d/dx[ e^y ] and d/dx[ ln y ]
d/dx[e^y] = e^y · dy/dx    (chain rule: outer = e^u, inner = y)

d/dx[ln y] = 1y · dy/dx    (chain rule: outer = ln u, inner = y)
Full Tricky Case Reference
d/dx [ y² ]
Chain rule: outer = u², inner = y
= 2y · dy/dx
d/dx [ y⁴ ]
Chain rule: outer = u⁴, inner = y
= 4y³ · dy/dx
d/dx [ x·y² ]
Product rule: f = x, g = y²
f′ = 1, g′ = 2y·dy/dx
= y² + 2xy · dy/dx
d/dx [ x³y ]
Product rule: f = x³, g = y
f′ = 3x², g′ = dy/dx
= 3x²y + x³ · dy/dx
d/dx [ e^(xy) ]
Chain rule: outer = e^u, inner = xy
d/dx[xy] = y + x·dy/dx
= e^(xy) · (y + x·dy/dx)
d/dx [ sin(xy) ]
Chain rule: outer = sin(u), inner = xy
d/dx[xy] = y + x·dy/dx
= cos(xy) · (y + x·dy/dx)
Practice · Tricky Cases
Problem
Find dy/dx for:   x²y + y³ = 5
1
Differentiate the left side — two separate terms
Term 1: d/dx[x²y] — this is a product (f = x², g = y)
= 2x·y + x²·dy/dx

Term 2: d/dx[y³] — chain rule on y
= 3y²·dy/dx
→ x²y needs product rule first, then dy/dx on the y part. y³ only needs chain rule.
2
Differentiate the right side, write full equation
d/dx[5] = 0

2xy + x²·dy/dx + 3y²·dy/dx = 0
3
Collect dy/dx terms, factor
dy/dx(x² + 3y²) = −2xy
4
Isolate dy/dx
dy/dx = −2xyx² + 3y²
Problem
Find dy/dx for:   sin(x) + cos(y) = 1
Step 1 — Differentiate both sides. What does d/dx[cos(y)] require?
Step 2 — Write the full differentiated equation
Step 3 — Isolate dy/dx
d/dx[sin x] = cos x
d/dx[cos y] = −sin y · dy/dx  (chain rule on y)

cos x + (−sin y · dy/dx) = 0
−sin y · dy/dx = −cos x

dy/dx = cos x / sin y = cot x · csc y   (or simply cos x / sin y)
Problem
Find dy/dx for:   e^(xy) = x + y
Left: d/dx[e^(xy)] = e^(xy) · d/dx[xy] = e^(xy) · (y + x·dy/dx)
Right: d/dx[x + y] = 1 + dy/dx

Full equation: e^(xy)(y + x·dy/dx) = 1 + dy/dx

Expand: ye^(xy) + xe^(xy)·dy/dx = 1 + dy/dx

Collect dy/dx: xe^(xy)·dy/dx − dy/dx = 1 − ye^(xy)
dy/dx(xe^(xy) − 1) = 1 − ye^(xy)

dy/dx = (1 − ye^(xy)) / (xe^(xy) − 1)
4.4

Tangent Lines Using Implicit Differentiation

The Procedure

Finding a tangent line always uses point-slope form: y − y₁ = m(x − x₁). The only new step is finding the slope m using implicit differentiation, then substituting the specific point.

  1. Implicitly differentiate the equation to find dy/dx.→ Your answer will be in terms of both x and y.
  2. Plug in the given point (x₁, y₁) to get a numerical slope.→ Substitute x = x₁ and y = y₁ into your dy/dx expression.
  3. Write the tangent line using point-slope form.→ y − y₁ = m(x − x₁). Simplify to slope-intercept if the problem asks.
⚠️ Verify the point is on the curve first. Before finding the tangent line, confirm the given point actually satisfies the original equation. Plugging a point that's not on the curve gives a meaningless answer.
Practice · Tangent Lines Implicitly
Problem
Find the equation of the tangent line to   x² + y² = 25   at the point (3, 4).
1
Verify the point is on the curve
3² + 4² = 9 + 16 = 25 ✓   The point (3, 4) is on x² + y² = 25.
2
Find dy/dx (we already did this in 4.2)
Differentiating x² + y² = 25:
2x + 2y·dy/dx = 0  →  dy/dx = −x/y
3
Substitute the point to get slope m
At (3, 4):   m = −3/4
4
Write tangent line in point-slope form
y − 4 = −34(x − 3)

Simplify: y = −34x + 94 + 4 = −34x + 254
→ This is the tangent to the circle at (3,4) — perpendicular to the radius at that point, as expected.
Problem
Find the tangent line to   x²y + y² = 6   at the point (1, 2).
Step 1 — Verify (1, 2) is on the curve: plug in and check
Step 2 — Implicitly differentiate x²y + y² = 6 (product rule on x²y)
Step 3 — Collect dy/dx terms and solve for dy/dx
Step 4 — Plug in (1, 2) to find m, then write the tangent line
Verify: (1)²(2) + (2)² = 2 + 4 = 6 ✓

d/dx[x²y] = 2xy + x²·dy/dx  |  d/dx[y²] = 2y·dy/dx

2xy + x²·dy/dx + 2y·dy/dx = 0
dy/dx(x² + 2y) = −2xy
dy/dx = −2xy / (x² + 2y)

At (1,2): m = −2(1)(2) / (1 + 4) = −4/5

y − 2 = −(4/5)(x − 1)  →  y = −(4/5)x + 14/5
Problem
Find the tangent line to   x³ + y³ = 9   at the point (1, 2).
Verify: 1 + 8 = 9 ✓

Differentiate: 3x² + 3y²·dy/dx = 0
dy/dx = −x²/y²

At (1, 2): m = −1/4

y − 2 = −(1/4)(x − 1)  →  y = −(1/4)x + 9/4
4.5

Second Derivatives Implicitly

The Procedure

To find d²y/dx², you differentiate dy/dx again with respect to x. Since dy/dx contains y (which is a function of x), you will need implicit differentiation a second time.

  1. Find dy/dx using implicit differentiation.→ Complete the first differentiation fully before starting the second.
  2. Differentiate dy/dx with respect to x to get d²y/dx².→ Treat dy/dx as a quotient or expression. Every y term gets dy/dx attached again (chain rule still applies).
  3. Substitute the expression for dy/dx wherever it appears in your result.→ This eliminates dy/dx from d²y/dx² and gives a cleaner final form.
  4. Simplify — the answer will be in terms of x and y.→ This is expected and correct for implicit d²y/dx².
Fully Worked Example — x² + y² = 25
Step 1 — First derivative (already found)
dy/dx = −x/y
Step 2 — Differentiate −x/y with respect to x (quotient rule)
d²y/dx² = d/dx[−x/y]

= (−1)·y − (−x)·dy/dxy² = −y + x·dy/dxy²
Step 3 — Substitute dy/dx = −x/y
= −y + x · (−x/y)y² = −y − x²/yy² = −y² − x²y³

Since x² + y² = 25:    d²y/dx² = −25y³
💡 Clean-up trick: After substituting dy/dx, look for opportunities to use the original equation. Here x² + y² = 25 let us replace x² + y² and collapse the answer dramatically.
Practice · Second Derivatives Implicitly
Problem
Find d²y/dx² for:   xy = 4
1
Find dy/dx — differentiate xy = 4
Product rule: y + x·dy/dx = 0
x·dy/dx = −y
dy/dx = −y/x
2
Differentiate −y/x with respect to x (quotient rule)
d²y/dx² = d/dx[−y/x]

= −dy/dx·x − (−y)·1x² = −x·dy/dx + yx²
→ Quotient rule: f = −y, g = x, f′ = −dy/dx, g′ = 1.
3
Substitute dy/dx = −y/x
= −x·(−y/x) + yx² = y + yx² = 2yx²

d²y/dx² = 2y/x²
→ Since xy = 4, y = 4/x, so we could also write d²y/dx² = 8/x³. Both correct.
Problem
Find d²y/dx² for:   x² − y² = 1
Step 1 — Differentiate implicitly to find dy/dx
Step 2 — Differentiate dy/dx = x/y with respect to x (quotient rule)
Step 3 — Substitute dy/dx = x/y into the result
Step 4 — Simplify (look for the original equation x² − y² = 1)
dy/dx = x/y

d²y/dx² = (y·1 − x·dy/dx) / y² = (y − x·(x/y)) / y²

= (y² − x²) / y³

Since x² − y² = 1 → y² − x² = −1:

d²y/dx² = −1/y³
Problem
Find d²y/dx² for:   y² = 4x. Then evaluate at the point (1, 2).
Differentiate: 2y·dy/dx = 4 → dy/dx = 2/y

Differentiate again: d²y/dx² = d/dx[2/y] = d/dx[2y⁻¹]
= −2y⁻² · dy/dx = −2/y² · (2/y) = −4/y³

d²y/dx² = −4/y³

At (1, 2): d²y/dx² = −4/8 = −1/2
