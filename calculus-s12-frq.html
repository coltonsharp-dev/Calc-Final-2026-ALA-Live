12.1

Theorem Citation Templates

How Graders Score Theorem Citations

When an FRQ asks you to "justify" or "explain" using a theorem, graders look for three things: the conditions are stated, the theorem is named, and the conclusion directly addresses the question. Missing any one of these costs the justification point.

Intermediate Value Theorem
IVT — Existence of a specific output value
Full Citation Template
Since f is continuous on [a, b] and f(a) = ___ and f(b) = ___, and since k = ___ is between f(a) and f(b), by the Intermediate Value Theorem there exists at least one c in (a, b) such that f(c) = k.
When the Problem Gives a Table
Since f is differentiable (hence continuous) on [a, b], and f(a) = ___ < k < f(b) = ___, by the Intermediate Value Theorem there exists a c in (a, b) such that f(c) = k.
❌ Never cite IVT without stating continuity first. It is a required condition. Graders will not award the justification point if continuity is implied but not written.
Extreme Value Theorem
EVT — Existence of absolute extrema on a closed interval
Citation Template
Since f is continuous on the closed interval [a, b], by the Extreme Value Theorem f attains both an absolute maximum value and an absolute minimum value on [a, b].
When Asked to Find the Extrema (Closed Interval Method)
Since f is continuous on [a, b], by EVT the absolute extrema exist. Evaluating f at the critical numbers and endpoints: f(c₁) = ___, f(c₂) = ___, f(a) = ___, f(b) = ___. The absolute maximum is ___ at x = ___, and the absolute minimum is ___ at x = ___.
Mean Value Theorem — Most Tested
MVT — Existence of a point where instantaneous rate = average rate
Full Citation Template
Since f is differentiable on (a, b) and continuous on [a, b], by the Mean Value Theorem there exists at least one c in (a, b) such that f′(c) = [f(b) − f(a)] / (b − a) = ___.
Table Version — When Given Values, Not a Formula
Since f is differentiable on (a, b) (given), by the Mean Value Theorem there exists a c in (a, b) such that f′(c) = [f(b) − f(a)] / (b − a) = (___ − ___) / (___ − ___) = ___.
💡 AP shortcut: If the problem says "f is differentiable," you automatically also have continuity (differentiability implies continuity). You still should state both conditions, but differentiable is the stronger one — lead with it.
Rolle's Theorem
Rolle's — Existence of a horizontal tangent
Citation Template
Since f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b) = ___, by Rolle's Theorem there exists at least one c in (a, b) such that f′(c) = 0.
⚠️ Rolle's requires all three conditions. Equal endpoint values is the condition that distinguishes Rolle's from MVT. If f(a) ≠ f(b), Rolle's does not apply — use MVT instead.
Practice · Writing Theorem Citations
Problem — MVT FRQ
The table shows values of a differentiable function f: f(1) = 4, f(5) = 12. Must there be a value c in (1, 5) where f′(c) = 2? Justify.
1
State the conditions
f is differentiable on (1, 5) — given. Since differentiable implies continuous, f is also continuous on [1, 5]. ✓
2
Compute the average rate of change
[f(5) − f(1)] / (5 − 1) = (12 − 4) / 4 = 2
3
Cite MVT with the full template
"Since f is differentiable on (1, 5) and continuous on [1, 5], by the Mean Value Theorem there exists at least one c in (1, 5) such that f′(c) = [f(5) − f(1)] / (5 − 1) = 2."

Yes — MVT guarantees it.
Problem — IVT FRQ
f is continuous on [0, 4], f(0) = −3, f(4) = 7. Does f have a zero on (0, 4)? Justify using IVT.
State continuity on [0, 4]
Show that k = 0 is between f(0) and f(4)
Write the IVT conclusion
f is continuous on [0, 4] (given). f(0) = −3 < 0 < 7 = f(4), so k = 0 is between f(0) and f(4).

"Since f is continuous on [0, 4] and f(0) = −3 < 0 < 7 = f(4), by the Intermediate Value Theorem there exists at least one c in (0, 4) such that f(c) = 0."

Yes — f has a zero on (0, 4).
Problem — Rolle's FRQ
f(x) = x³ − 3x. Verify Rolle's Theorem applies on [0, √3], then find all values of c.
f is a polynomial → continuous on [0, √3] and differentiable on (0, √3). ✓
f(0) = 0 and f(√3) = 3√3 − 3√3 = 0. So f(0) = f(√3) = 0. ✓

All three conditions of Rolle's Theorem are satisfied.

By Rolle's Theorem, there exists at least one c in (0, √3) such that f′(c) = 0.
f′(x) = 3x² − 3 = 0 → x² = 1 → x = 1.
c = 1 ∈ (0, √3) ✓

c = 1
12.2

Explaining Integrals & Derivatives in Context

What Graders Expect — Context Language

When an FRQ asks "what does this integral represent?" or "interpret this value," you must answer in plain English using the units and context of the problem. Mathematical notation alone does not earn full credit.

Interpreting a Definite Integral in Context
The Pattern
∫ab R(t) dt = [context-specific quantity] from t = a to t = b, in [units]

Key words: "total amount", "net change in", "accumulated"
❌ Loses Points
"∫₀⁵ R(t) dt is the integral of R from 0 to 5."

This is just restating notation — no context, no units, no meaning stated.
✓ Earns Points
"∫₀⁵ R(t) dt represents the total amount of water, in gallons, that flowed into the tank during the first 5 minutes."

Context + quantity + units = full credit.
Interpreting a Derivative in Context
The Pattern
f′(c) = k means: [f′ describes] is changing at a rate of k [units of f′] at [context of c]

Key words: "rate of change", "increasing/decreasing at", "per [time unit]"
❌ Loses Points
"f′(3) = 5 means the derivative is 5 at t = 3."

No context. Doesn't say what quantity or what units.
✓ Earns Points
"f′(3) = 5 means the temperature is increasing at a rate of 5 degrees per hour at time t = 3 hours."

Quantity + direction + rate + units + time.
Context Language Reference — Fill in the Blanks
ExpressionSentence Template
∫ab R(t) dt The total [quantity], in [units], from t = a to t = b.
Q(a) + ∫ab R(t) dt The total [quantity] at time t = b, starting from [initial amount] at t = a.
f′(c) = k The [quantity] is [increasing/decreasing] at a rate of k [units] per [time unit] at t = c.
∫ab |v(t)| dt The total distance traveled, in [units], from t = a to t = b.
∫ab v(t) dt The displacement (net change in position), in [units], from t = a to t = b.
(1/(b−a))∫f dx The average value of [quantity] over the interval [a, b].
Practice · Interpretation in Context
Problem
The number of cars in a parking lot at time t hours is modeled by P(t). P′(2) = −8. Interpret this value in context.
1
Identify what P′ measures
P is the number of cars. P′ is the rate of change of the number of cars with respect to time.
2
Interpret the sign
P′(2) = −8 < 0 → the number of cars is decreasing at t = 2.
3
Write the complete context sentence
"At time t = 2 hours, the number of cars in the parking lot is decreasing at a rate of 8 cars per hour."
Problem
Oil leaks from a tank at rate L(t) gallons per hour. Write a sentence interpreting ∫₀⁶ L(t) dt = 42.
What does an integral of a rate represent?
Write the full interpretation sentence with quantity, units, and time interval
"∫₀⁶ L(t) dt = 42 represents the total amount of oil, 42 gallons, that leaked from the tank during the first 6 hours."
Problem
A particle's position is given by x(t). Interpret each: (a) x′(3) = −5. (b) ∫₀⁴ |x′(t)| dt = 18. (c) ∫₀⁴ x′(t) dt = −2.
(a) At time t = 3, the particle is moving in the negative direction at a speed of 5 units per second. (x′ = velocity; negative means leftward/negative direction)

(b) The total distance traveled by the particle from t = 0 to t = 4 is 18 units. (|v(t)| gives speed; integral gives total path length)

(c) The net displacement of the particle from t = 0 to t = 4 is −2 units. (velocity integral = displacement; negative means net leftward motion)
12.3

The Complete Point-Loss Checklist

Most Common FRQ Point Losses — In Order of Frequency
  • ❌Missing +C on indefinite integrals. Every indefinite integral answer must end with +C. No exceptions. One point deducted per occurrence.
  • ❌Theorem cited without stating conditions. Saying "by MVT, f′(c) = 2" without stating differentiability/continuity earns no justification credit.
  • ❌Interpretation without units or context. "The integral equals 15" earns nothing. Must say what 15 represents, in what units, over what time.
  • ❌Not showing setup for area/volume problems. Writing only the final number without the integral expression loses the setup point.
  • ❌Washer formula written as [R−r]² instead of [R]²−[r]². Algebraically different. Always square first, then subtract.
  • ❌FTC Part 1 + chain rule: forgetting g′(x). If upper limit is g(x), multiply by g′(x). Omitting it makes the answer wrong.
  • ❌Not verifying the inflection point sign change. Setting f″ = 0 is not enough — must show f″ changes sign. Otherwise it's not an inflection point.
  • ❌Using Second Derivative Test when f″(c) = 0. The test is inconclusive. Must use the First Derivative Test in that case.
  • ❌Plugging values into related rates before differentiating. Differentiate first. Substitute only after the derivative equation is written.
  • ❌Confusing displacement and total distance. ∫v dt = displacement (signed). ∫|v| dt = total distance. Different answers, different integrals.
  • ❌Not splitting area when curves cross. If f and g switch which is on top, split the integral at the crossing. Integrating f−g across a crossing gives wrong sign for part of the region.
  • ❌Rounding a non-decimal answer. Unless told to approximate, leave answers in exact form: 9π/2, ln 3, √5, etc.
What to Always Show — Grader Checklist
  • ✓Show the integral setup before evaluating. Write ∫[...] dx before you compute it. The setup is often worth a point on its own.
  • ✓Show all antiderivative steps. Don't skip from ∫ directly to F(b)−F(a) without writing F(x) first.
  • ✓Justify sign changes explicitly. "f′ changes from negative to positive at x = 2, therefore f has a local minimum at x = 2."
  • ✓State the conclusion of every theorem clearly. After citing the theorem, state what c is (or what it guarantees).
  • ✓Label your sign chart clearly. Mark the intervals, the sign of f′ in each, and the conclusion (increasing/decreasing, max/min).
  • ✓Include units in context answers. Gallons per minute, meters, degrees Fahrenheit — always match the problem's units.
12.4

How AP Graders Actually Score FRQs

The Rubric Structure

Each FRQ part is worth 1–4 points. Points are typically structured as:

Point TypeWhat It RewardsHow to Earn It
Setup PointWriting the correct integral or expression before evaluatingAlways write the expression first. Never jump to the answer.
Antiderivative PointFinding the correct antiderivativeEarned even if the final arithmetic is wrong — show your work.
Answer PointCorrect final numerical valueFollow-through credit — wrong start can still earn this if process is right.
Justification PointLogical reasoning or theorem citation that answers "why"Use theorem templates. State conditions. Name the theorem. State the conclusion.
Interpretation PointContextual explanation of a mathematical resultFull sentence with quantity + units + time interval. No math notation alone.
💡 Follow-through credit: If you make an error in part (a) but carry that value correctly through parts (b) and (c), you can still earn the answer points in (b) and (c). Show all your work and don't leave parts blank.
⚠️ Crossed out work is not graded. If you cross something out and write a replacement, only the replacement is scored. Be deliberate about what you cross out.

Practice · Full FRQ Part — Put It All Together
Full FRQ Part — Rate Problem
Water drains from a pool at rate D(t) = 50 − 2t gallons per hour (0 ≤ t ≤ 10). At t=0 the pool has 400 gallons.
(a) Find the amount drained from t=2 to t=8.
(b) How many gallons are in the pool at t=8?
(c) At what rate is the pool draining at t=6? Is the draining rate increasing or decreasing? Justify.
1
(a) Total drained = ∫₂⁸ D(t) dt
= ∫28 (50−2t) dt = [50t − t²]28
= (400−64) − (100−4) = 336 − 96 = 240 gallons
2
(b) Amount at t=8 = Q(0) − ∫₀⁸ D(t) dt
∫08(50−2t)dt = [50t−t²]08 = 400−64 = 336
Q(8) = 400 − 336 = 64 gallons
→ We subtract because water is draining out, reducing the total.
3
(c) Rate and justification
D(6) = 50 − 12 = 38 gallons per hour.

D′(t) = −2 < 0 for all t. So D′(6) = −2 < 0.
"The draining rate is decreasing at t = 6 because D′(6) = −2 < 0, which means D is a decreasing function."
Problem
A differentiable function f has the values: f(0)=3, f(2)=9, f(4)=5, f(6)=11.
(a) Use a Right Riemann Sum with n=3 to approximate ∫₀⁶ f(x) dx.
(b) Must there be a c in (0,6) where f′(c) = (f(6)−f(0))/(6−0)? Justify with the name of the theorem and both conditions.
(a) Δx = 2, right endpoints = x=2,4,6. Compute the sum.
(b) State both conditions of MVT for f on [0,6]
(b) Compute the average rate of change, then write the MVT conclusion
(a) R = 2×(f(2)+f(4)+f(6)) = 2×(9+5+11) = 2×25 = 50

(b) f is differentiable on (0,6) (given). Since differentiable implies continuous, f is continuous on [0,6]. Both conditions of MVT are met. ✓

AROC = (11−3)/(6−0) = 8/6 = 4/3

"Since f is differentiable on (0,6) and continuous on [0,6], by the Mean Value Theorem there exists at least one c in (0,6) such that f′(c) = 4/3."

Yes, there must be such a c.
Full Multi-Part — Graph Analysis FRQ
The graph of f′ is given (you must reason from it). f is differentiable everywhere. f′ > 0 on (0,3), f′ < 0 on (3,7), f′ changes sign from − to + at x=7, f′(3) = 0.

(a) Find all x in (0,8) where f has a local minimum. Justify.
(b) Find all x in (0,8) where f has a local maximum. Justify.
(c) On what interval is f concave up? Justify using f″.
(a) f has a local minimum at x = 7. Justification: f′ changes from negative to positive at x = 7, so by the First Derivative Test, f has a local minimum at x = 7.

(b) f has a local maximum at x = 3. Justification: f′ changes from positive to negative at x = 3, so by the First Derivative Test, f has a local maximum at x = 3.

(c) f is concave up where f″ > 0, which is where f′ is increasing. From the graph of f′: f′ is increasing on the intervals where the graph of f′ slopes upward. State the specific interval based on the graph. Justify: "f″ = (f′)′ > 0 on (___) because f′ is increasing there."
