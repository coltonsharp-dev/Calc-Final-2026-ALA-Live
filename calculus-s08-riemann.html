8.1

What a Riemann Sum Is

The Core Idea

A Riemann sum approximates the area under a curve by filling the region with rectangles (or trapezoids). Each rectangle has a width of Δx and a height determined by the function value at a chosen point in the subinterval.

The approximation gets more accurate as the number of rectangles increases. In the limit as n → ∞, the Riemann sum becomes the exact definite integral.

The Setup
Divide [a, b] into n equal subintervals, each of width:

Δx = b − an

The partition points are: x₀ = a, x₁ = a + Δx, x₂ = a + 2Δx, …, xₙ = b

Each subinterval is [xᵢ₋₁, xᵢ]
Sigma Notation — Reading the Sum
n
Σ
i=1
f(xᵢ*) · Δx
Σ = sum  |  i = index  |  xᵢ* = chosen point in each subinterval  |  Δx = width of each rectangle
The choice of xᵢ* (left endpoint, right endpoint, midpoint) determines the type of sum.
8.2

Left Riemann Sum

Left Riemann Sum (LRS)
L = Δx · [f(x₀) + f(x₁) + f(x₂) + ··· + f(xₙ₋₁)]

Use the left endpoint of each subinterval as the rectangle height.
Last point used: xₙ₋₁ = b − Δx   (NOT b itself)
The left endpoint is the start of each subinterval. For n subintervals you use n function values: x₀ through xₙ₋₁.
Overestimates  when f is increasing (↗) Underestimates  when f is decreasing (↘)
Blue rectangles use left endpoint heights. On an increasing function, they fall short of the curve → underestimate.

8.3

Right Riemann Sum

Right Riemann Sum (RRS)
R = Δx · [f(x₁) + f(x₂) + f(x₃) + ··· + f(xₙ)]

Use the right endpoint of each subinterval as the rectangle height.
First point used: x₁ = a + Δx   Last point used: xₙ = b
The right endpoint is the end of each subinterval. For n subintervals you use n function values: x₁ through xₙ.
Overestimates  when f is decreasing (↘) Underestimates  when f is increasing (↗)
💡 Left vs Right pattern: Left sum = skip the last x value (xₙ). Right sum = skip the first x value (x₀). Everything else is the same formula structure.

8.4

Midpoint Riemann Sum

Midpoint Riemann Sum (MRS)
M = Δx · [f(m₁) + f(m₂) + ··· + f(mₙ)]

where each midpoint: mᵢ = xᵢ₋₁ + xᵢ2 (average of left and right endpoints of each subinterval)
Generally the most accurate of the three rectangle-based methods. The midpoint height balances the overcount on one side with the undercount on the other.
Accuracy depends on concavity Overestimates on concave down (∩), underestimates on concave up (∪)
⚠️ Midpoints may not appear in the table. On FRQs, if the table gives only left/right endpoints of subintervals, you may need to average two adjacent x-values to find the midpoint. If midpoint values aren't given, the midpoint sum can't be computed from that table — use left or right instead.

8.5

Trapezoidal Rule

Trapezoidal Rule (Not a True Riemann Sum)
T = Δx2 · [f(x₀) + 2f(x₁) + 2f(x₂) + ··· + 2f(xₙ₋₁) + f(xₙ)]

Shortcut: T = L + R2 (average of Left and Right Riemann sums)
Uses trapezoids instead of rectangles. The top of each trapezoid connects two adjacent function values with a straight line. Better accuracy than either Left or Right alone.
Overestimates  on concave up (∪) Underestimates  on concave down (∩)
Why the Trapezoidal Rule Is Not a True Riemann Sum

A Riemann sum always uses rectangles — a single function value multiplied by the width. The trapezoidal rule uses trapezoids, averaging two function values at each step. This makes it more accurate but technically a different approximation method. On the AP exam, this distinction is tested — be ready to state it.

ℹ️ The L + R shortcut: T = (L + R)/2 works perfectly when the subintervals are equal width. This is the fastest way to compute the trapezoid approximation if you've already found L and R.

8.6

Over vs Underestimate — Master Logic

The Complete Decision Table
Methodf increasing (↗)f decreasing (↘)f concave up (∪)f concave down (∩)
Left (L) Underestimate Overestimate — —
Right (R) Overestimate Underestimate — —
Midpoint (M) — — Underestimate Overestimate
Trapezoid (T) — — Overestimate Underestimate
💡 Memory shortcut for Left/Right: The LEFT sum "falls behind" on an increasing function (it uses old, smaller values) → underestimate. On a decreasing function it "sticks above" → overestimate. RIGHT is the opposite in every case.
💡 Memory shortcut for Trap/Midpoint: On concave up (∪), the trapezoid lies ABOVE the curve (overestimate). The midpoint tangent lies BELOW the curve (underestimate). On concave down (∩): flip both. Trap and midpoint are always opposite each other.
8.7

Riemann Sum as the Definition of the Definite Integral

The Limit Connection

As the number of subintervals n → ∞ (and Δx → 0), the Riemann sum becomes exact. This is the formal definition of the definite integral:

Formal Definition
∫ab f(x) dx = limn→∞ nΣi=1 f(xᵢ*) · Δx

where Δx = b−an and xᵢ* is any point in the i-th subinterval

This is why numerical approximations (Riemann sums) get better with more rectangles — they're approaching the true value of the definite integral from below, above, or alternating sides depending on the choice of endpoint.

Reading a Riemann Sum in Sigma Notation — FRQ Skill
Identify what integral this sum approaches
limn→∞ nΣi=1 in · 1n

Identify: Δx = 1/n → b−a = 1, so [0,1]
xᵢ = i/n (right endpoints of [0,1] with n subintervals)
f(xᵢ) = xᵢ = i/n → f(x) = x

= ∫₀¹ x dx = [x²/2]₀¹ = 1/2
⚠️ FRQ skill: Recognizing that a given sigma notation sum equals a specific definite integral is tested directly. The key is identifying Δx (the 1/n factor) and xᵢ (the i/n expression) to reconstruct f(x) and the bounds.
