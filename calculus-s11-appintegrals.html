11.1

Area Between Two Curves

The Core Formula

The area between two curves f(x) (top) and g(x) (bottom) on an interval [a, b] is found by integrating the vertical distance between them:

Area Between Curves — Vertical Slices (functions of x)
A = ∫ab [f(x) − g(x)] dx

where f(x) is the top function and g(x) is the bottom function on [a, b]
⚠️ Critical: f(x) − g(x) must be ≥ 0 throughout [a,b]. Always subtract bottom from top. If the curves switch which is on top, you must split the integral at the crossing point.
Step-by-Step Setup
  1. Find the intersection points.→ Set f(x) = g(x) and solve. These are the limits of integration a and b unless the problem gives them.
  2. Determine which function is on top.→ Pick a test value in [a,b]. Whichever gives the larger output is f(x) = top. The area formula is always top minus bottom.
  3. Check whether the curves switch.→ If they cross inside [a,b], split the integral at the crossing point. Each piece uses its own top−bottom ordering.
  4. Set up and evaluate ∫[f−g] dx.
  5. State the answer with units² if given context.
The shaded region is the area between f (green, top) and g (blue, bottom). Each vertical slice has height f(x)−g(x) and width dx.
Practice · Area Between Two Curves
Problem
Find the area between f(x) = x + 2 and g(x) = x² from x = −1 to x = 2.
1
Determine which is on top — test x = 0
f(0) = 2, g(0) = 0. Since 2 > 0, f(x) = x+2 is on top.
2
Verify no crossings on (−1, 2)
Set x+2 = x²: x²−x−2 = (x−2)(x+1) = 0 → x = −1 and x = 2.
Crossings are exactly at the endpoints — no crossings inside. ✓
3
Set up the integral
A = ∫−12 [(x+2) − x²] dx = ∫−12 (x + 2 − x²) dx
4
Evaluate using FTC Part 2
= [x²2 + 2x − x³3]−12
F(2) = 2 + 4 − 8/3 = 6 − 8/3 = 10/3
F(−1) = 1/2 − 2 + 1/3 = −7/6
A = 10/3 − (−7/6) = 20/6 + 7/6 = 27/6 = 9/2
Problem
Find the area enclosed by y = 4 − x² and y = x + 2.
Step 1 — Find intersection points: set 4−x² = x+2
Step 2 — Test x=0 to determine which is on top
Step 3 — Set up and write the integral (top minus bottom)
Step 4 — Find the antiderivative and evaluate
4−x² = x+2 → x²+x−2 = 0 → (x+2)(x−1) = 0 → x = −2, 1

Test x=0: 4−0=4 > 0+2=2 → 4−x² is on top

A = ∫−21 [(4−x²) − (x+2)] dx = ∫−21 (2−x−x²) dx

= [2x − x²/2 − x³/3]−21
F(1) = 2 − 1/2 − 1/3 = 7/6
F(−2) = −4 − 2 + 8/3 = −10/3

A = 7/6 + 10/3 = 7/6 + 20/6 = 27/6 = 9/2
Problem
Find the total area between y = x³ − x and y = 0 from x = −1 to x = 1. (Hint: the curves cross at x = 0.)
x³−x = x(x²−1) = x(x−1)(x+1). On [−1,0]: x³−x ≥ 0 (test x=−0.5: −0.125+0.5>0). On [0,1]: x³−x ≤ 0.

Split at x=0:
A = ∫−10(x³−x)dx + ∫01−(x³−x)dx

∫(x³−x)dx = x⁴/4 − x²/2
F(0)−F(−1) = 0 − (1/4−1/2) = 1/4
F(1)−F(0) = (1/4−1/2) = −1/4 → absolute value = 1/4

Total area = 1/4 + 1/4 = 1/2
11.2

Volumes of Revolution — Disk Method

The Idea

When a region is rotated around an axis, it sweeps out a 3D solid. The disk method computes volume by slicing the solid into thin disks perpendicular to the axis of rotation. Each disk has radius r = f(x) and thickness dx.

Area of one disk = πr² = π[f(x)]². Integrate over the interval to get the total volume.

Disk Method
V = π ∫ab [f(x)]² dx
Use when rotating around the x-axis (or a horizontal line) and there is no hole in the solid — the region touches the axis.
When Rotating Around y-axis
V = π ∫cd [g(y)]² dy
Rewrite x as a function of y. Integrate with respect to y using y-bounds. Same formula, different variable.
Each thin disk has radius f(x) and thickness dx. Integrating π[f(x)]² from a to b gives total volume.
Practice · Disk Method
Problem
Find the volume when y = √x is rotated around the x-axis from x = 0 to x = 4.
1
Identify f(x) and the axis
f(x) = √x. Rotating around the x-axis. Use the disk method: V = π∫[f(x)]² dx.
2
Square f(x)
[f(x)]² = (√x)² = x
→ Squaring eliminates the square root — a key simplification that often happens with √x.
3
Set up and evaluate the integral
V = π∫04 x dx = π[x²2]04 = π · 162 = 8π
Problem
Find the volume when y = x² is rotated around the x-axis from x = 0 to x = 3.
Step 1 — Write the disk method formula with f(x) = x²
Step 2 — Simplify [x²]² and find the antiderivative
Step 3 — Evaluate from 0 to 3
V = π∫03 x⁴ dx = π[x⁵/5]03 = π(243/5 − 0) = 243π/5
Problem
Find the volume when y = 2x is rotated around the x-axis from x = 0 to x = 2.
V = π∫02 (2x)² dx = π∫02 4x² dx = π[4x³/3]02 = π(32/3) = 32π/3
11.3

Volumes of Revolution — Washer Method

When to Use the Washer Method

Use the washer method when there is a hole in the solid — the region being rotated does not touch the axis of rotation. The cross-sections are washers (annuli), not solid disks.

Each washer has an outer radius R (from the axis to the top curve) and inner radius r (from the axis to the bottom curve). The washer area = π(R² − r²).

Washer Method — Rotating Around the x-axis
V = π ∫ab {[R(x)]² − [r(x)]²} dx

R(x) = outer radius = distance from axis to the top/outer curve
r(x) = inner radius = distance from axis to the bottom/inner curve
❌ Do NOT write [R−r]². The correct formula is [R]² − [r]². Squaring must happen before subtracting. [R−r]² ≠ R²−r² in general.
Disk vs Washer — How to Decide
Use Disk when:
• The region touches the axis of rotation
• Only one boundary function exists
• Inner radius = 0

Formula: V = π∫[f(x)]² dx
Use Washer when:
• The region has a gap between it and the axis
• Two curves bound the region
• Inner radius > 0

Formula: V = π∫([R]²−[r]²) dx
R(x) = outer radius (axis to outer curve). r(x) = inner radius (axis to inner curve). Washer area = π(R²−r²). Never write [R−r]².
Practice · Washer Method
Problem
Find the volume of the solid formed when the region between y = x and y = x² on [0,1] is rotated around the x-axis.
1
Identify the outer and inner radius
On [0,1]: y = x is above y = x² (test x=0.5: 0.5 > 0.25 ✓)
Rotating around x-axis → distances are the y-values.
Outer radius: R(x) = x
Inner radius: r(x) = x²
→ Outer = farther from axis = larger y-value = top curve.
2
Write the washer formula
V = π∫01 {[x]² − [x²]²} dx = π∫01 (x² − x⁴) dx
3
Evaluate
= π[x³3 − x⁵5]01 = π(13 − 15) = π · 215 = 2π/15
Problem
Find the volume when the region between y = √x and y = x² on [0,1] is rotated around the x-axis.
Step 1 — Which curve is on top on [0,1]? Test x = 0.5
Step 2 — Write the washer integral π∫([R]² − [r]²)dx on [0,1]
Step 3 — Evaluate and simplify
√(0.5) ≈ 0.707 > 0.25 → outer R = √x, inner r = x²

V = π∫01[(√x)² − (x²)²]dx = π∫01(x − x⁴)dx
= π[x²/2 − x⁵/5]01 = π(1/2 − 1/5) = π(3/10) = 3π/10
Problem
Find the volume when the region between y = 3 and y = x + 1 on [0,2] is rotated around the x-axis.
On [0,2]: y=3 is above y=x+1 (at x=0: 3>1, at x=2: 3=3, so y=3 is outer for most of interval; at x=2 they meet).
R(x) = 3, r(x) = x+1

V = π∫02[9 − (x+1)²]dx = π∫02[9 − x² − 2x − 1]dx
= π∫02(8 − 2x − x²)dx
= π[8x − x² − x³/3]02
= π(16 − 4 − 8/3) = π(12 − 8/3) = π(28/3) = 28π/3
11.4

Accumulation & Total Change from a Rate

The most common FRQ application type
The Core Idea

If R(t) is the rate of change of some quantity Q, then the total change in Q from t = a to t = b is:

Total Change from a Rate
∫ab R(t) dt = Q(b) − Q(a) = total change in Q

If you also know Q(a), then:   Q(b) = Q(a) + ∫ab R(t) dt
FRQ Context Language — What These Mean
FRQ PhraseWhat It's AskingHow to Compute
"Total amount that entered from t=a to t=b"Net accumulation of inflow∫ab Rin(t) dt
"Amount at time t=b"Initial + changeQ(a) + ∫ab R(t) dt
"Is the amount increasing or decreasing at t=c?"Sign of R(c)If R(c) > 0 → increasing; R(c) < 0 → decreasing
"Net change in position"Displacement∫ab v(t) dt
"Total distance traveled"Unsigned total path∫ab |v(t)| dt
⚠️ Displacement vs Distance: ∫v(t)dt gives displacement (net, signed). ∫|v(t)|dt gives total distance (always positive, split at zeros of v). This distinction appears on almost every AP exam.
Practice · Accumulation & Total Change
Problem — FRQ Style
Water flows into a tank at rate R(t) = 3t² + 2 gallons per minute. At t=0, the tank contains 10 gallons.
(a) How many gallons enter from t=0 to t=4?
(b) How many gallons are in the tank at t=4?
(c) Is the amount in the tank increasing or decreasing at t=3? Justify.
1
(a) Total gallons entering — integrate the rate
∫04 R(t) dt = ∫04 (3t² + 2) dt
= [t³ + 2t]04 = (64 + 8) − 0 = 72 gallons
2
(b) Amount at t=4: initial + total change
Q(4) = Q(0) + ∫04 R(t) dt = 10 + 72 = 82 gallons
3
(c) Increasing or decreasing at t=3
R(3) = 3(9) + 2 = 29 > 0.
The amount is increasing at t=3 because R(3) > 0 — the rate of flow is positive, so water is still entering.
Problem
A particle moves along a line with velocity v(t) = t² − 4 (m/s). Find: (a) displacement from t=0 to t=3. (b) total distance from t=0 to t=3.
(a) Displacement = ∫₀³ v(t) dt. Find the antiderivative and evaluate.
(b) Find where v(t)=0 on [0,3] to split for total distance
(b) Total distance = ∫₀² |v| dt + ∫₂³ |v| dt = −∫₀² v dt + ∫₂³ v dt
(a) ∫03(t²−4)dt = [t³/3−4t]03 = (9−12)−0 = −3 m (net displacement)

(b) v(t) = t²−4 = 0 at t=2. On [0,2]: v<0. On [2,3]: v>0.
Total distance = |∫02(t²−4)dt| + ∫23(t²−4)dt
= |[t³/3−4t]02| + [t³/3−4t]23
= |(8/3−8)| + (9−12−8/3+8) = |−16/3| + (8/3−3) = 16/3 + (−1/3) = 15/3 = 5 m
Problem — FRQ Style
People enter a store at rate E(t) = 40 + 2t and leave at rate L(t) = 10 + 5t (people/hour). At t=0, there are 50 people in the store.
(a) How many people enter from t=0 to t=6?
(b) How many people are in the store at t=6?
(c) At what rate is the number changing at t=3? Is it increasing or decreasing?
(a) ∫06 E(t) dt = ∫06(40+2t)dt = [40t+t²]06 = 240+36 = 276 people entered

(b) Net rate = E(t)−L(t) = (40+2t)−(10+5t) = 30−3t
∫06(30−3t)dt = [30t−3t²/2]06 = 180−54 = 126
People at t=6: 50+126 = 176 people

(c) Net rate at t=3: E(3)−L(3) = (46)−(25) = 21 people/hour. Increasing because E(3)−L(3) > 0.
11.5

Average Value of a Function

The Formula

The average value of f(x) on [a, b] is the single number that, if you extended it as a horizontal line, would create the same area under f as the actual function does:

Average Value
favg = 1b − a ∫ab f(x) dx

This is the Mean Value Theorem for Integrals: there exists c ∈ (a,b) where f(c) = favg.
Practice · Average Value
Problem
Find the average value of f(x) = x² on [1, 4].
1
Apply the average value formula
favg = 14−1 ∫14 x² dx = 13 [x³3]14
2
Evaluate the integral
13 · [643 − 13] = 13 · 633 = 639 = 7
Problem
Find the average value of g(x) = sin x on [0, π].
Write the average value formula with a=0, b=π
Evaluate ∫₀^π sin x dx
Multiply by 1/(b−a) to get the average
favg = (1/π)∫0π sin x dx = (1/π)[−cos x]0π
= (1/π)(−cos π + cos 0) = (1/π)(1+1) = 2/π
Problem
The temperature in a room (°F) over 6 hours is modeled by T(t) = 70 + 4t − t². Find the average temperature from t=0 to t=6.
Tavg = (1/6)∫06(70+4t−t²)dt
= (1/6)[70t+2t²−t³/3]06
= (1/6)(420+72−72) = (1/6)(420) = 70°F
