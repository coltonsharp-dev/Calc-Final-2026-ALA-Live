3.1

The Basic Rules

Power · Constant · Sum/Difference
Power Rule
ddx [xn] = n · xn−1
Multiply by the exponent, then subtract 1 from the exponent. Works for any real n — including fractions and negatives.
Examples
ddx[x⁵] = 5x⁴  |  ddx[x1/2] = 12x−1/2  |  ddx[x−3] = −3x−4  |  ddx[√x] = 12√x
❌ Common mistake: Forgetting to rewrite before differentiating. √x = x1/2 and 1/x³ = x−3 before applying the rule.
Constant Rule & Constant Multiple Rule
ddx[c] = 0      ddx[c·f(x)] = c · f′(x)
Constants vanish. Scalar multipliers survive unchanged through differentiation.
Sum / Difference Rule
ddx[f ± g] = f′(x) ± g′(x)
Differentiate term by term. Addition and subtraction survive as-is.
Practice · Basic Rules
Problem
Find f′(x) for f(x) = 4x³ − 2x² + 5√x − 7
1
Rewrite everything as powers of x
f(x) = 4x³ − 2x−2 + 5x1/2 − 7
→ Fractions and roots must be converted before the power rule applies.
2
Apply power rule term by term
4x³ → 12x²
−2x−2 → −2·(−2)x−3 = 4x−3
5x1/2 → 5·(12)x−1/2 = 52x−1/2
−7 → 0
3
Reassemble and simplify notation
f′(x) = 12x² + 4x³ + 52√x
→ Convert negative exponents back to fraction notation for clean final form.
Problem
Find g′(x) for g(x) = 3x⁴ − 6x³ + 8√x + 2
Step 1 — Rewrite each term as a power of x
Step 2 — Differentiate each term using the power rule
Step 3 — Write the final answer with clean notation
g(x) = 3x⁴ − 6x−3 + 8x1/2 + 2

g′(x) = 12x³ + 18x−4 + 4x−1/2

g′(x) = 12x³ + 18x⁴ + 4√x
Problem
Find h′(x) for h(x) = 5x⁶ + 4x − 3x2/3 + 9
Rewrite: h(x) = 5x⁶ + 4x−1 − 3x2/3 + 9

5x⁶ → 30x⁵
4x−1 → −4x−2
−3x2/3 → −2x−1/3
9 → 0

h′(x) = 30x⁵ − 4x² − 2x1/3
3.2

Product Rule

Product Rule
ddx[f · g] = f′ · g + f · g′
Memory: "derivative of first times second, PLUS first times derivative of second." — d/dx[uv] = u′v + uv′
❌ Most common mistake: d/dx[f·g] ≠ f′·g′. You cannot just differentiate each factor separately. You must use the product rule formula.
Practice · Product Rule
Problem
Differentiate: y = (3x² + 1)(x³ − 5x)
1
Label f and g
f = 3x² + 1    g = x³ − 5x
2
Find f′ and g′
f′ = 6x    g′ = 3x² − 5
3
Apply: f′g + fg′
= (6x)(x³ − 5x) + (3x² + 1)(3x² − 5)
= 6x⁴ − 30x² + 9x⁴ − 15x² + 3x² − 5
= 15x⁴ − 42x² − 5
→ Expand each product fully, then collect like terms.
Problem
Differentiate: y = (x² + 3)(2x − 1)
Step 1 — Label f and g, then find f′ and g′
Step 2 — Write out f′g + fg′ (don't simplify yet)
Step 3 — Expand and collect like terms
f = x² + 3, g = 2x − 1, f′ = 2x, g′ = 2

y′ = (2x)(2x − 1) + (x² + 3)(2)
= 4x² − 2x + 2x² + 6
= 6x² − 2x + 6
Problem
Differentiate: y = (4x³ − x)(x² + 2x)
f = 4x³ − x, g = x² + 2x, f′ = 12x² − 1, g′ = 2x + 2

y′ = (12x² − 1)(x² + 2x) + (4x³ − x)(2x + 2)
= 12x⁴ + 24x³ − x² − 2x + 8x⁴ + 8x³ − 2x² − 2x
= 20x⁴ + 32x³ − 3x² − 4x
3.3

Quotient Rule

Including trig & e^x cases
Quotient Rule
ddx fg = f′·g − f·g′g²
Memory chant: "Low d-high minus high d-low, over low-squared we go." — Low = denominator, High = numerator, d = derivative of.
❌ Order matters. It's f′g − fg′, NOT fg′ − f′g. The numerator derivative goes first. Swapping the order changes the sign of your answer.
Quotient Rule With Trig — Fully Worked
Example: Differentiate y = sin(x) / x²
f = sin x  →  f′ = cos x
g = x²  →  g′ = 2x

y′ = cos(x)·x² − sin(x)·2x(x²)² = x·cos(x) − 2·sin(x)x³
Example: Differentiate y = tan(x) — derive it from sin/cos
y = sin xcos x   f = sin x, f′ = cos x  |  g = cos x, g′ = −sin x

y′ = cos x · cos x − sin x · (−sin x)cos²x = cos²x + sin²xcos²x = 1cos²x = sec²x
Quotient Rule With e^x — Fully Worked
Example: Differentiate y = e^x / (x² + 1)
f = e^x  →  f′ = e^x  (e^x is its own derivative)
g = x² + 1  →  g′ = 2x

y′ = e^x·(x² + 1) − e^x·2x(x² + 1)² = e^x(x² + 1 − 2x)(x² + 1)² = e^x(x − 1)²(x² + 1)²
💡 e^x shortcut: Since (e^x)′ = e^x, every time e^x appears as the numerator, factor it out of the result. This almost always gives a cleaner final form.
Practice · Quotient Rule
Problem
Differentiate: y = cos xx³
1
Label and differentiate
f = cos x → f′ = −sin x
g = x³ → g′ = 3x²
→ d/dx[cos x] = −sin x. The negative sign is critical — it's the most dropped sign in all of calculus.
2
Apply f′g − fg′ over g²
y′ = (−sin x)(x³) − (cos x)(3x²)(x³)² = −x³ sin x − 3x² cos xx⁶
3
Factor and simplify
= x²(−x sin x − 3 cos x)x⁶ = −x sin x − 3 cos xx⁴
→ Cancel x² from numerator and denominator.
Problem
Differentiate: y = e^xx³ + 1
Step 1 — Identify f, g, f′, g′
Step 2 — Write out f′g − fg′ (unsimplified)
Step 3 — Factor e^x from the numerator and simplify
f = e^x, f′ = e^x  |  g = x³ + 1, g′ = 3x²

y′ = e^x(x³+1) − e^x(3x²)(x³+1)²

= e^x(x³ − 3x² + 1)(x³ + 1)²
Problem
Differentiate: y = sin xe^x
f = sin x, f′ = cos x  |  g = e^x, g′ = e^x

y′ = cos x · e^x − sin x · e^x(e^x)² = e^x(cos x − sin x)e^(2x)

= cos x − sin xe^x
3.4

Trig Derivatives

Full table + memory system
The Full Table — 6 Functions
d/dx [ sin x ]
= cos x
sin → cos (no negative)
d/dx [ cos x ]
= −sin x
cos → −sin (negative!)
d/dx [ tan x ]
= sec²x
tan → sec² (squared)
d/dx [ cot x ]
= −csc²x
cot → −csc² (negative + squared)
d/dx [ sec x ]
= sec x · tan x
sec → sec·tan (same function × tan)
d/dx [ csc x ]
= −csc x · cot x
csc → −csc·cot (negative + same × cot)
💡 Memory system — The co-function rule: Every "co-" function derivative (cos, cot, csc) gets a negative sign. Non-co functions (sin, tan, sec) are positive. Then the pattern inside mirrors: sin↔cos, tan↔sec², sec↔sec·tan.
⚠️ The #1 trig derivative error: Writing d/dx[cos x] = sin x (missing the negative). Every exam, every year. The negative on cos x is non-negotiable.
Practice · Trig Derivatives
Problem
Differentiate: y = x² · tan x   (requires product rule + trig derivative)
1
Identify — this is a product
f = x²,   g = tan x
2
Differentiate each
f′ = 2x  |  g′ = sec²x
3
Apply product rule
y′ = (2x)(tan x) + (x²)(sec²x)
= 2x tan x + x² sec²x
Problem
Differentiate: y = 3 sin x − 5 cos x + 2 tan x
Differentiate term by term — what is d/dx of each?
Write the full answer
d/dx[3 sin x] = 3 cos x
d/dx[−5 cos x] = +5 sin x  (negative × negative = positive)
d/dx[2 tan x] = 2 sec²x

y′ = 3 cos x + 5 sin x + 2 sec²x
Problem
Differentiate: y = sec xx² + 1
Quotient rule: f = sec x, f′ = sec x tan x  |  g = x²+1, g′ = 2x

y′ = (sec x tan x)(x²+1) − (sec x)(2x)(x²+1)²

Factor sec x from numerator:

y′ = sec x [(x²+1) tan x − 2x](x²+1)²

Differentiate: y = x³ · e^x   (product rule + e^x)
1
Label the product
f = x³ → f′ = 3x²  |  g = e^x → g′ = e^x
2
Apply product rule
y′ = (3x²)(e^x) + (x³)(e^x)

What rule applies? (ln of a function)

f(x) = x²+4, f′(x) = 2x

y′ = 2xx² + 4

3.6

Chain Rule

Most used rule on the AP exam
Chain Rule
ddx[f(g(x))] = f′(g(x)) · g′(x)
Memory: "derivative of the outside (leaving the inside alone) times derivative of the inside." — d/dx[outer(inner)] = outer′(inner) · inner′
Step-by-Step Procedure
  1. Identify the outer and inner functions.→ Outer = the outermost operation. Inner = what's plugged into it.
  2. Differentiate the outer function, leave the inner function alone.→ Treat the inner function as a single unit at this step.
  3. Multiply by the derivative of the inner function.→ This is the "chain" — the inner function's rate of change multiplies through.
Worked Examples
y = (3x + 1)⁵  →  outer = u⁵, inner = 3x+1  →  y′ = 5(3x+1)⁴ · 3 = 15(3x+1)⁴

y = sin(x²)  →  outer = sin(u), inner = x²  →  y′ = cos(x²) · 2x = 2x cos(x²)

y = e^(sin x)  →  outer = e^u, inner = sin x  →  y′ = e^(sin x) · cos x

y = ln(5x² − 1)  →  outer = ln(u), inner = 5x²−1  →  y′ = 10x5x²−1
Chain Rule Inside FTC Part 1 — Critical AP Topic

When the upper limit of an integral is a function of x (not just x itself), the chain rule must be applied when differentiating:

FTC Part 1 + Chain Rule
ddx ∫ag(x) f(t) dt = f(g(x)) · g′(x)

Example:   ddx ∫1x³ sin(t) dt = sin(x³) · 3x² = 3x² sin(x³)
❌ Most common FTC Part 1 error: Writing only f(g(x)) and forgetting to multiply by g′(x). The chain rule factor is always required when the upper limit is not just x.
Chain Rule in Reverse — Preview of U-Substitution

Every time you write f(g(x)) · g′(x) as a derivative, you're looking at the antiderivative pattern for u-substitution. This is exactly why u-sub works:

Chain Rule → U-Sub Connection
If   ddx[F(g(x))] = F′(g(x)) · g′(x) = f(g(x)) · g′(x)

Then:   ∫ f(g(x)) · g′(x) dx = F(g(x)) + C

← This is the integral pattern that u-sub exploits. When you see a composite function multiplied by the derivative of its inner function, u-sub will solve it.
Practice · Chain Rule
Problem
Differentiate: y = cos³(x)   [read as (cos x)³]
1
Identify outer and inner
y = [cos x]3  →  outer = u³,   inner = cos x
2
Differentiate outer, leave inner alone
outer′ = 3[cos x]² = 3cos²x
3
Multiply by inner′
inner′ = d/dx[cos x] = −sin x

y′ = 3cos²x · (−sin x) = −3cos²x sin x
→ The negative comes from the derivative of cos x — it's required.
Problem
Differentiate: y = e^(x² + 3)
Step 1 — Identify outer and inner functions
Step 2 — Differentiate the outer (leave inner alone), then find inner′
Step 3 — Multiply them together
outer = e^u, inner = x²+3
outer′(inner) = e^(x²+3)
inner′ = 2x

y′ = e^(x²+3) · 2x = 2xe^(x²+3)
Problem
Find: ddx ∫0x⁴ cos(t²) dt
FTC Part 1 + Chain Rule:
Upper limit g(x) = x⁴ → g′(x) = 4x³
f(t) = cos(t²) → plug in upper limit: f(x⁴) = cos((x⁴)²) = cos(x⁸)

Answer = cos(x⁸) · 4x³ = 4x³ cos(x⁸)
3.7

Logarithmic Differentiation

Variable exponents · Large products
When to Use It

Use logarithmic differentiation when a function has:

  • ①   A variable in the exponent — like y = x^(sin x) or y = (2x+1)^(x²)
  • ②   A large product or quotient of many terms — taking ln simplifies the structure dramatically
The 5-Step Method
  1. Take ln of both sides: ln y = ln[f(x)]→ ln converts exponents to multipliers, products to sums, quotients to differences.
  2. Simplify using log properties (ln(ab) = ln a + ln b, ln(a^n) = n·ln a)→ This is why we took ln — it makes the expression differentiable.
  3. Differentiate both sides with respect to x.→ Left side: d/dx[ln y] = y′/y (chain rule). Right side: normal differentiation.
  4. Solve for y′: multiply both sides by y.→ y′ = y · (right side result)
  5. Substitute back: replace y with the original function.→ Final answer is in terms of x only.
Practice · Logarithmic Differentiation
Problem
Differentiate: y = x^x
1
Why regular rules fail
x^x has a variable in both base and exponent. Power rule needs a constant exponent. Exponential rule needs a constant base. Neither applies — use log diff.
2
Take ln of both sides
ln y = ln(x^x) = x · ln x
→ ln(a^n) = n·ln a brings the exponent down as a multiplier.
3
Differentiate both sides (implicit on left)
y′y = (1)·ln x + x·1x = ln x + 1
→ Left: d/dx[ln y] = y′/y by chain rule. Right: product rule on x·ln x.
4
Solve for y′, substitute back
y′ = y(ln x + 1) = x^x (ln x + 1)
Problem
Differentiate: y = (sin x)^x
Step 1 — Take ln of both sides and simplify
Step 2 — Differentiate both sides (product rule on the right, y′/y on the left)
Step 3 — Multiply both sides by y, substitute back
ln y = x · ln(sin x)

y′/y = (1)·ln(sin x) + x · cos xsin x = ln(sin x) + x·cot x

y′ = y[ln(sin x) + x cot x]

y′ = (sin x)^x [ln(sin x) + x cot x]
Problem
Differentiate: y = (x²+1)³√(x+5) using logarithmic differentiation
ln y = 3·ln(x²+1) − 12·ln(x+5)

y′y = 6xx²+1 − 12(x+5)

y′ = y · [6xx²+1 − 12(x+5)]

y′ = (x²+1)³√(x+5) · [6xx²+1 − 12(x+5)]
