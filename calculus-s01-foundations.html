1.1

The Unit Circle

What It Is

The unit circle is a circle of radius 1 centered at the origin. Every point on it has coordinates (cos θ, sin θ) where θ is the angle measured counterclockwise from the positive x-axis.

You need to know the exact values — not decimals — at 16 standard angles. These values appear constantly in derivatives, integrals, and limit problems.

Core Identity
For any angle θ on the unit circle:
x = cos θ  ·  y = sin θ  ·  tan θ = sin θ / cos θ

And always:  sin²θ + cos²θ = 1
Memory Method — The √ Pattern

For the first quadrant (0° to 90°), sin values follow this pattern as the angle goes from 0° → 30° → 45° → 60° → 90°:

sin:   √02 ,  √12 ,  √22 ,  √32 ,  √42  =   0 , 12 , √22 , √32 , 1

cos: same values, reversed order

cos:   1 , √32 , √22 , 12 , 0
💡 The trick: Count up under the radical for sin (√0, √1, √2, √3, √4), count down for cos. Then simplify. That's the entire first quadrant.

For other quadrants, the magnitude stays the same — only the signs change based on where you are:

Q1 (+, +)  |  Q2 (−, +)  |  Q3 (−, −)  |  Q4 (+, −)

Practice · Unit Circle Values
Problem
Find the exact values of sin(225°), cos(225°), and tan(225°).
1
Locate the angle
225° = 180° + 45°. That puts us in Quadrant III — exactly 45° past the negative x-axis.
→ In Q3, both sin and cos are negative.
2
Find the reference angle
Reference angle = 225° − 180° = 45°. This is the acute angle between our terminal side and the x-axis.
→ Reference angle tells us the magnitude. The quadrant tells us the sign.
3
Read values at 45°, apply Q3 signs
At 45°: sin = √22, cos = √22
In Q3 both are negative:
sin(225°) = −√22  |  cos(225°) = −√22
4
Find tan
tan(225°) = sin/cos = −√2/2−√2/2 = 1
→ Negative ÷ negative = positive. tan is positive in Q3.
Problem
Find the exact values of sin(330°), cos(330°), and tan(330°).
Step 1 — What quadrant is 330°?
Step 2 — What is the reference angle? (reference angle = 360° − 330°)
Step 3 — What are sin and cos at that reference angle?
Step 4 — Apply the correct signs for Q4, then compute tan.
Q4 → sin negative, cos positive.
Reference angle = 30°. At 30°: sin = 1/2, cos = √3/2.

sin(330°) = −1/2
cos(330°) = √3/2
tan(330°) = (−1/2) ÷ (√3/2) = −1/√3 = −√3/3

Find the exact values of sin(120°), cos(120°), and tan(120°).

At 60°: sin = √3/2, cos = 1/2

sin(120°) = √3/2
cos(120°) = −1/2
tan(120°) = (√3/2) ÷ (−1/2) = −√3

Limits

Informal Definition

The limit of f(x) as x approaches a is the value that f(x) gets arbitrarily close to as x gets close to a — regardless of what f(a) actually equals (or whether it even exists).

Notation
limx→a f(x) = L

Read: "The limit of f(x) as x approaches a equals L"
⚠️ Critical distinction: The limit asks what f(x) approaches — NOT what it equals at x = a. The function can be undefined at a and the limit can still exist.
One-Sided Limits

You can approach a from the left or from the right separately:

limx→a⁻ f(x)  = limit from the left (x comes from values less than a)

limx→a⁺ f(x)  = limit from the right (x comes from values greater than a)

The two-sided limit exists only when both one-sided limits are equal.
When a Limit Does NOT Exist — 3 Cases
  • Case 1: Left ≠ Right limx→a⁻ f(x) ≠ limx→a⁺ f(x) → DNE (jump discontinuity)
  • Case 2: Unbounded behavior f(x) → ±∞ as x → a → DNE (vertical asymptote)
  • Case 3: Oscillation f(x) oscillates without settling → DNE (e.g., limx→0 sin(1/x))
Limit Laws — You Can Split Limits Apart

If both lim f(x) and lim g(x) exist as x→a, then:

LawRule
Sumlim [f + g] = lim f + lim g
Differencelim [f − g] = lim f − lim g
Scalarlim [c·f] = c · lim f
Productlim [f · g] = lim f · lim g
Quotientlim [f / g] = lim f / lim g   (if lim g ≠ 0)
Powerlim [f(x)]ⁿ = [lim f(x)]ⁿ
Limits at Infinity — Horizontal Asymptotes

When x → ±∞, look at the degree of numerator vs denominator:

  • Degree top < bottom: limit = 0 e.g., limx→∞ (3x)/(x² + 1) = 0
  • Degree top = bottom: limit = ratio of leading coefficients e.g., limx→∞ (5x²)/(2x²) = 5/2
  • Degree top > bottom: limit = ±∞ (DNE) e.g., limx→∞ (x³)/(x) = ∞
💡 Shortcut: Divide every term by the highest power of x in the denominator, then apply limit term by term. Each x term → 0, constants survive.
Practice · Evaluating Limits
Problem
Evaluate:   limx→3 x² − 9x − 3
1
Try direct substitution first
Plug x = 3: 9 − 93 − 3 = 00  → indeterminate form. Cannot stop here.
→ 0/0 means factor and cancel — it does NOT mean the limit is 0 or undefined.
2
Factor the numerator
x² − 9 = (x − 3)(x + 3)   (difference of squares)
→ a² − b² = (a−b)(a+b). Here a = x, b = 3.
3
Cancel the common factor
(x − 3)(x + 3)(x − 3) = (x + 3)   for x ≠ 3
→ Valid because the limit approaches x = 3, but never equals it, so we can cancel.
4
Now substitute
limx→3 (x + 3) = 3 + 3 = 6
Problem
Evaluate:   limx→2 x² − 4x − 2
Step 1 — Try direct substitution. What do you get?
Step 2 — Factor the numerator x² − 4 (difference of squares)
Step 3 — Cancel the common factor with the denominator
Step 4 — Evaluate the simplified expression at x = 2
Direct sub → 0/0 (indeterminate).
x² − 4 = (x − 2)(x + 2)
Cancel (x − 2): simplified = (x + 2)
limx→2 (x + 2) = 4
Problem
Evaluate:   limx→−1 x² + 3x + 2x + 1
Direct sub → 0/0 (indeterminate).
x² + 3x + 2 = (x + 1)(x + 2)
Cancel (x + 1): simplified = (x + 2)
limx→−1 (x + 2) = 1
Practice · Limits at Infinity
Problem
Evaluate:   limx→∞ 4x² − 3x + 12x² + 5
1
Compare degrees
Top degree = 2, bottom degree = 2. Same degree → limit equals the ratio of leading coefficients.
2
Divide everything by x²
= lim 4 − 3/x + 1/x²2 + 5/x²
→ As x→∞: 3/x → 0, 1/x² → 0, 5/x² → 0
3
Apply limits
= 4 − 0 + 02 + 0 = 4/2 = 2
Problem
Evaluate:   limx→∞ 6x³ − x3x³ + 2x²
Step 1 — What are the degrees of the numerator and denominator?
Step 2 — Divide every term by x³ (the highest power)
Step 3 — Apply the limit (all x terms → 0). What remains?
Both degree 3. Divide by x³:
lim (6 − 1/x²) / (3 + 2/x) = (6 − 0)/(3 + 0) = 2
Problem
Evaluate:   limx→∞ 5x + 3x² − 1
Top degree (1) < bottom degree (2) → limit = 0

Verify: divide by x²: (5/x + 3/x²)/(1 − 1/x²) → 0/1 = 0 ✓
1.3

Continuity

The 3 Conditions for Continuity at x = a

A function f is continuous at x = a if and only if ALL THREE conditions hold:

  • f(a) is defined → The function must actually exist at that point. A hole or asymptote breaks this.
  • limx→a f(x) exists → Left and right limits must both exist and be equal.
  • limx→a f(x) = f(a) → The limit must equal the actual function value. A defined point in the wrong spot breaks this.
❌ Common mistake: Only checking that f(a) exists. You need all three. A function can be defined at a point but still not be continuous there if the limit doesn't equal f(a).
Types of Discontinuities
TypeWhat HappensRemovable?Example
Removable (Hole) Limit exists but ≠ f(a), or f(a) undefined ✓ Yes (x²−4)/(x−2) at x=2
Jump Left limit ≠ right limit ✗ No Piecewise with gap
Infinite f(x) → ±∞ (vertical asymptote) ✗ No 1/x at x=0
💡 Removable means you could redefine the function at that single point to make it continuous — that's why it's called removable. You're removing the discontinuity by patching the hole.
Practice · Checking Continuity
Problem
Is the following function continuous at x = 2?

f(x) = x² − 4 / (x − 2)   when x ≠ 2,   and   f(2) = 5
1
Check Condition 1 — Is f(2) defined?
f(2) = 5 is explicitly given. ✓ Defined.
2
Check Condition 2 — Does limx→2 f(x) exist?
Factor: (x² − 4)/(x − 2) = (x−2)(x+2)/(x−2) = (x + 2) for x ≠ 2
limx→2 (x + 2) = 4. Limit exists ✓
3
Check Condition 3 — Does lim = f(2)?
lim = 4, but f(2) = 5. 4 ≠ 5. Condition 3 FAILS.
→ The function is NOT continuous at x = 2. It's a removable discontinuity (hole at height 4, but the point is plotted at height 5).
Problem
Is g(x) = (x² − 9)/(x − 3), with g(3) = 6, continuous at x = 3?
Condition 1 — Is g(3) defined?
Condition 2 — Find limx→3 g(x) by factoring the numerator
Condition 3 — Does the limit equal g(3)?
g(3) = 6 ✓ defined
x² − 9 = (x−3)(x+3) → cancel → limx→3 (x+3) = 6
Limit (6) = g(3) (6) ✓

Yes, g is continuous at x = 3.
Problem
h(x) = (x + 4) for x < 1, and h(x) = (x² + 2) for x ≥ 1. Is h continuous at x = 1?
h(1) = 1² + 2 = 3 ✓ defined

Left limit (x→1⁻): h(x) = x + 4 → 1 + 4 = 5
Right limit (x→1⁺): h(x) = x² + 2 → 1 + 2 = 3

Left limit (5) ≠ Right limit (3) → lim DNE

h is NOT continuous at x = 1. It's a jump discontinuity.
