Section 02 · AP Calculus AB

The
Theorems

Five theorems — IVT, EVT, MVT, Rolle's, and the Squeeze Theorem. Each one broken down into what it says, when you can use it, and the exact language graders expect in an FRQ.

Theorem 01
Intermediate Value Theorem
IVT
Plain English

If a function is continuous on a closed interval and you pick any output value between f(a) and f(b), there must be at least one input in that interval that produces it. In other words: a continuous function cannot skip over values.

Formal Statement
IVT
If f is continuous on [a, b] and k is any value between f(a) and f(b),
then there exists at least one c ∈ (a, b) such that f(c) = k.
Conditions — Both Must Be Met
  • ① f is continuous on [a, b] — must be stated and verified before citing IVT
  • ② k is between f(a) and f(b) — you must show the target value is actually in the range of outputs on the interval
❌ Common mistake: Forgetting to confirm continuity first. If the function has a jump or hole on [a,b], IVT does not apply — no matter what the values look like.
Visual Intuition
FRQ Citation Template
Since f is continuous on [a, b] and f(a) = ___ and f(b) = ___, and since k = ___ is between f(a) and f(b), by the Intermediate Value Theorem there exists at least one c in (a, b) such that f(c) = k.

Fill in the blanks with the numbers from the specific problem. Always state continuity explicitly — it's a required condition, and graders will deduct without it.

Practice · IVT Application
Problem
Let f(x) = x³ − 4x + 1. Show there exists a value c in (0, 2) where f(c) = 0.
1
Verify continuity
f(x) = x³ − 4x + 1 is a polynomial. Polynomials are continuous everywhere, so f is continuous on [0, 2]. ✓
→ You must say this out loud in an FRQ — don't assume graders infer it.
2
Evaluate the endpoints
f(0) = 0 − 0 + 1 = 1
f(2) = 8 − 8 + 1 = 1... wait — let me use (0, 3) instead.
f(0) = 1  |  f(3) = 27 − 12 + 1 = 16
→ We need k = 0 to be between the two endpoint values.
3
Check that k is between f(a) and f(b)
f(0) = 1 > 0, so try f at a negative endpoint. f(−3) = −27 + 12 + 1 = −14 < 0.
So f(−3) = −14 < 0 < 1 = f(0). The value k = 0 lies between them. ✓
4
Cite IVT
Since f is continuous on [−3, 0] and f(−3) = −14 < 0 < 1 = f(0), by IVT there exists at least one c ∈ (−3, 0) such that f(c) = 0.
Problem
Let g(x) = x² − 5. Show there exists a c in (2, 3) where g(c) = 0.
Step 1 — What type of function is g(x)? Is it continuous on [2, 3]?
Step 2 — Evaluate g(2) and g(3)
Step 3 — Is k = 0 between g(2) and g(3)?
Step 4 — Write the IVT conclusion in full
g(x) = x² − 5 is a polynomial → continuous everywhere, including [2, 3]. ✓

g(2) = 4 − 5 = −1  |  g(3) = 9 − 5 = 4

−1 < 0 < 4 → k = 0 is between g(2) and g(3). ✓

Since g is continuous on [2, 3] and g(2) = −1 < 0 < 4 = g(3), by the Intermediate Value Theorem there exists at least one c ∈ (2, 3) such that g(c) = 0.
Problem
h(x) = e^x − 3. Show there exists a c in (1, 2) where h(c) = 0. Write a complete FRQ-style justification.
h(x) = e^x − 3 is continuous everywhere (exponential function). ✓

h(1) = e − 3 ≈ 2.718 − 3 = −0.282 < 0
h(2) = e² − 3 ≈ 7.389 − 3 = 4.389 > 0

−0.282 < 0 < 4.389 → k = 0 lies between h(1) and h(2). ✓

Since h is continuous on [1, 2] and h(1) < 0 < h(2), by the Intermediate Value Theorem there exists at least one c ∈ (1, 2) such that h(c) = 0.
Theorem 02
Extreme Value Theorem
EVT
Plain English

If a function is continuous on a closed interval, it is guaranteed to reach both an absolute maximum and an absolute minimum somewhere on that interval. The extremes cannot be missed — they must actually be achieved.

Formal Statement
EVT
If f is continuous on [a, b], then f attains an absolute maximum value f(M) and an absolute minimum value f(m) for some M, m ∈ [a, b].
Conditions — Both Must Be Met
  • ① f is continuous on [a, b] — a single discontinuity can allow the function to avoid its extremes
  • ② The interval is closed [a, b] — EVT fails on open intervals. On (a, b), the function might approach but never reach the extreme.
⚠️ EVT guarantees existence — not location. It says the max and min exist. Finding where they are requires the Closed Interval Method (check critical points AND endpoints).
Closed Interval Method — Finding the Actual Extrema
  1. ①Find all critical numbers (where f′ = 0 or f′ undefined) on (a, b)
  2. ②Evaluate f at every critical number AND at both endpoints a and b
  3. ③The largest value is the absolute max. The smallest is the absolute min.
FRQ Citation Template
Since f is continuous on the closed interval [a, b], by the Extreme Value Theorem f attains both an absolute maximum and an absolute minimum on [a, b].

EVT is most often used to justify why a maximum or minimum must exist before you go find it — it's the "it exists" statement, not the "here it is" statement.

Practice · EVT + Closed Interval Method
Problem
Find the absolute maximum and minimum of f(x) = x³ − 3x² on [−1, 4].
1
Invoke EVT
f(x) = x³ − 3x² is a polynomial → continuous on [−1, 4]. By EVT, an absolute max and min exist on this interval. ✓
2
Find critical numbers — set f′ = 0
f′(x) = 3x² − 6x = 3x(x − 2)
f′(x) = 0 → x = 0 and x = 2
Both are in (−1, 4). ✓
→ Critical numbers are where the derivative is zero or undefined (inside the open interval).
3
Evaluate f at critical numbers AND endpoints
f(−1) = −1 − 3 = −4
f(0) = 0 − 0 = 0
f(2) = 8 − 12 = −4
f(4) = 64 − 48 = 16
4
Identify the extrema
Absolute Maximum: f(4) = 16
Absolute Minimum: f(−1) = f(2) = −4 (a tie — both are valid)
→ There can be multiple points achieving the same extreme value.
Problem
Find the absolute max and min of g(x) = x³ − 6x + 2 on [−2, 3].
Step 1 — Justify EVT applies
Step 2 — Find g′(x) and solve g′(x) = 0
Step 3 — Evaluate g at critical numbers and endpoints x = −2, 3
Step 4 — State the absolute max and min
Polynomial → continuous → EVT applies. ✓

g′(x) = 3x² − 6 = 0 → x² = 2 → x = ±√2 ≈ ±1.414. Both in (−2, 3). ✓

g(−2) = −8 + 12 + 2 = 6
g(−√2) = −2√2 + 6√2 + 2 = 4√2 + 2 ≈ 7.66
g(√2) = 2√2 − 6√2 + 2 = −4√2 + 2 ≈ −3.66
g(3) = 27 − 18 + 2 = 11

Absolute Maximum: g(3) = 11
Absolute Minimum: g(√2) = 2 − 4√2 ≈ −3.66
Problem
Find the absolute max and min of h(x) = −x² + 4x − 1 on [0, 5].
Polynomial → continuous → EVT applies. ✓

h′(x) = −2x + 4 = 0 → x = 2. In (0, 5). ✓

h(0) = 0 + 0 − 1 = −1
h(2) = −4 + 8 − 1 = 3
h(5) = −25 + 20 − 1 = −6

Absolute Maximum: h(2) = 3
Absolute Minimum: h(5) = −6
Theorem 03 · Most Important for FRQ
Mean Value Theorem
MVT
Plain English

If a function is smooth (differentiable) on an interval, then at some point the instantaneous rate of change (slope of the tangent line) must equal the average rate of change (slope of the secant line) over the whole interval.

Think of it as a driving analogy: if you average 60 mph over a trip, at some exact moment your speedometer must have read exactly 60 mph.

Formal Statement
MVT
If f is continuous on [a, b] and differentiable on (a, b),
then there exists at least one c ∈ (a, b) such that:

f′(c) = f(b) − f(a)b − a

Instantaneous rate of change = Average rate of change
Conditions — Both Required
  • ① Continuous on [a, b] — closed interval, no breaks
  • ② Differentiable on (a, b) — open interval (corners, cusps, or vertical tangents break this condition)
⚠️ Differentiability implies continuity — but not the reverse. If you confirm differentiable, continuity is automatic. However, you still need to state both conditions in an FRQ.
Visual Intuition

The green tangent at c is parallel to the dashed secant line connecting the endpoints.

FRQ Citation Template — This Is the Most Tested
Since f is differentiable on (a, b) [and continuous on [a, b]], by the Mean Value Theorem there exists at least one c ∈ (a, b) such that f′(c) = [f(b) − f(a)] / (b − a) = ___.

In many FRQs you are given a table of values. Compute the slope (average rate of change) from the table, then cite MVT to justify that f′ must equal that slope somewhere on the interval.

Practice · Mean Value Theorem
Problem
f(x) = x² − x on [1, 4]. Find the value of c guaranteed by MVT.
1
Verify conditions
f(x) = x² − x is a polynomial → continuous on [1, 4] and differentiable on (1, 4). MVT applies. ✓
2
Compute the average rate of change
f(1) = 1 − 1 = 0  |  f(4) = 16 − 4 = 12
Average rate = f(4) − f(1)4 − 1 = 12 − 03 = 4
3
Set f′(c) equal to the average rate
f′(x) = 2x − 1
Set f′(c) = 4:   2c − 1 = 4 → 2c = 5 → c = 5/2
4
Verify c is in the interval
c = 5/2 = 2.5 ∈ (1, 4) ✓
→ Always check! If c fell outside the interval, it would not satisfy MVT's conclusion.
Problem
g(x) = x³ on [0, 3]. Find the value of c guaranteed by MVT.
Step 1 — Verify MVT conditions for g(x) on [0, 3]
Step 2 — Compute the average rate of change [f(3)−f(0)] / (3−0)
Step 3 — Find g′(x), then solve g′(c) = AROC
Step 4 — Verify c ∈ (0, 3)
Polynomial → continuous on [0,3] and differentiable on (0,3). MVT applies. ✓

g(0) = 0, g(3) = 27 → AROC = (27 − 0)/(3 − 0) = 9

g′(x) = 3x² → set 3c² = 9 → c² = 3 → c = √3 ≈ 1.732

√3 ∈ (0, 3) ✓   c = √3
Problem
The table shows values of a differentiable function f: f(1) = 3, f(5) = 11. What does MVT guarantee, and what is the value of f′(c)?
f is differentiable (given) → continuous on [1, 5]. MVT applies. ✓

Average rate of change = (11 − 3)/(5 − 1) = 8/4 = 2

By MVT, there exists at least one c ∈ (1, 5) such that f′(c) = 2.

Note: MVT doesn't tell us the exact value of c here — only that it exists. If we had a formula for f we could solve for it.
Theorem 04
Rolle's Theorem
Special Case of MVT
Plain English

Rolle's is just MVT with one extra condition: f(a) = f(b). When the function starts and ends at the same height, the average rate of change is zero — so the guaranteed tangent slope is also zero. That means there's a horizontal tangent somewhere in between.

Formal Statement
Rolle's Theorem
If f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b),
then there exists at least one c ∈ (a, b) such that f′(c) = 0.
ℹ️ Rolle's vs MVT: Rolle's has 3 conditions (MVT's 2 + equal endpoint values). Its conclusion is always f′(c) = 0. MVT's conclusion is f′(c) = AROC which could be any number.
FRQ Citation Template
Since f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b) = ___, by Rolle's Theorem there exists at least one c ∈ (a, b) such that f′(c) = 0.
Practice · Rolle's Theorem
Problem
Verify Rolle's Theorem applies to f(x) = x² − 4x on [0, 4], then find c.
1
Check all 3 conditions
① Polynomial → continuous on [0, 4] ✓
② Polynomial → differentiable on (0, 4) ✓
③ f(0) = 0 − 0 = 0  |  f(4) = 16 − 16 = 0 → f(0) = f(4) = 0 ✓
→ All 3 conditions met. Rolle's Theorem applies.
2
Find c where f′(c) = 0
f′(x) = 2x − 4
Set f′(c) = 0: 2c − 4 = 0 → c = 2
3
Verify c ∈ (0, 4)
c = 2 ∈ (0, 4) ✓   This is the vertex of the parabola — the horizontal tangent point.
Problem
Verify Rolle's applies to g(x) = x³ − x on [−1, 1], then find all values of c.
Step 1 — Check the 3 conditions (continuity, differentiability, equal endpoints)
Step 2 — Find g′(x) and solve g′(c) = 0
Step 3 — Check which values of c are in (−1, 1)
Polynomial → continuous and differentiable ✓
g(−1) = −1 + 1 = 0  |  g(1) = 1 − 1 = 0 → f(−1) = f(1) ✓

g′(x) = 3x² − 1 = 0 → x² = 1/3 → x = ±1/√3 = ±√3/3

Both ±√3/3 ≈ ±0.577 ∈ (−1, 1) ✓

c = ±√3/3 ≈ ±0.577
Problem
Does Rolle's Theorem apply to h(x) = |x| on [−2, 2]? Explain. If not, which condition fails?
Check conditions:
① h(x) = |x| is continuous on [−2, 2] ✓
② h(x) = |x| is NOT differentiable at x = 0 (corner/cusp). 0 ∈ (−2, 2) → condition fails ✗
③ h(−2) = 2 = h(2) ✓

Rolle's Theorem does NOT apply because h is not differentiable on (−2, 2). Condition ② fails at x = 0.
Theorem 05
Squeeze Theorem
Sandwich Theorem
Plain English

If one function is trapped between two others that both approach the same limit, the trapped function must approach that limit too. The two outer functions "squeeze" it to the same value.

Formal Statement
Squeeze Theorem
If g(x) ≤ f(x) ≤ h(x) near x = a (not necessarily at x = a),
and limx→a g(x) = limx→a h(x) = L,
then limx→a f(x) = L.
Classic Application
Most Common Use
Prove:   limx→0 x² sin(1x) = 0

We know:   −1 ≤ sin(1/x) ≤ 1   for all x ≠ 0
Multiply by x²:   −x² ≤ x² sin(1/x) ≤ x²

limx→0 (−x²) = 0   and   limx→0 (x²) = 0

∴ limx→0 x² sin(1/x) = 0   by the Squeeze Theorem
💡 When to use it: Whenever you have a trig function (whose values are bounded between −1 and 1) multiplied by something that goes to 0. The product gets squeezed to 0.
Practice · Squeeze Theorem
Problem
Evaluate:   limx→0 x⁴ cos(1x²)
1
Bound the cosine function
We know −1 ≤ cos(anything) ≤ 1. So: −1 ≤ cos(1/x²) ≤ 1 for all x ≠ 0.
2
Multiply all sides by x⁴ (which is ≥ 0)
−x⁴ ≤ x⁴ cos(1/x²) ≤ x⁴
→ x⁴ ≥ 0 always, so inequality signs don't flip.
3
Take limits of the outer bounds
limx→0 (−x⁴) = 0   and   limx→0 (x⁴) = 0
4
Apply Squeeze Theorem
Both bounds approach 0, so: limx→0 x⁴ cos(1/x²) = 0
Problem
Evaluate:   limx→0 x² sin(3x)
Step 1 — Write the bounding inequality for sin(3/x)
Step 2 — Multiply all three parts by x² to bound the full expression
Step 3 — Evaluate the limits of both outer bounds as x → 0
Step 4 — State the conclusion using the Squeeze Theorem
−1 ≤ sin(3/x) ≤ 1
−x² ≤ x²sin(3/x) ≤ x²
limx→0(−x²) = 0 and limx→0(x²) = 0

By the Squeeze Theorem: limx→0 x²sin(3/x) = 0
Problem
Evaluate:   limx→0 x³ cos(5x). Be careful — does the sign of x³ matter?
−1 ≤ cos(5/x) ≤ 1

Multiply by x³: note x³ can be negative when x < 0, so we must use absolute value bounds instead:
−|x³| ≤ x³ cos(5/x) ≤ |x³|

limx→0 (−|x³|) = 0 and limx→0 |x³| = 0

By the Squeeze Theorem: limx→0 x³ cos(5/x) = 0
