6.1

What an Antiderivative Is

The Core Idea

Differentiation asks: "What is the rate of change of f?" — gives you f′.

Antidifferentiation asks: "What function has this as its derivative?" — reverses the process.

F(x) is an antiderivative of f(x) if F′(x) = f(x). The process of finding F is called integration, and f(x) is called the integrand.

Notation
∫ f(x) dx = F(x) + C

∫ = integral sign  |  f(x) = integrand  |  dx = variable of integration  |  F(x) = antiderivative  |  C = constant of integration
Differentiation and Antidifferentiation Are Inverses

They undo each other — with one catch. Differentiation destroys constant information. Antidifferentiation has to account for any constant that could have been there.

Differentiation
f(x) = x³ + 7
f′(x) = 3x²

f(x) = x³ − 4
f′(x) = 3x²

Both give the same derivative. The constant is lost.
Antidifferentiation
∫ 3x² dx = x³ + C

C represents any constant that could have been there — +7, −4, 0, or anything else.

We can't know the constant without more info (initial condition).
ℹ️ Family of antiderivatives: ∫ 3x² dx = x³ + C represents an entire family of functions — one for every value of C. The + C is not optional. It is part of the answer.
How To Read The Inverse Relationship
Derivative (→) Antiderivative (←)
d/dx [x⁴] = 4x³⟷∫ 4x³ dx = x⁴ + C
d/dx [sin x] = cos x⟷∫ cos x dx = sin x + C
d/dx [e^x] = e^x⟷∫ e^x dx = e^x + C
d/dx [ln x] = 1/x⟷∫ 1/x dx = ln|x| + C
6.2

The +C Rule

Most dropped point on the AP exam
Exactly When to Write +C and When Not To
ALWAYS write +C
Indefinite integrals — no bounds on the integral sign.

∫ x² dx = x³/3 + C
∫ cos x dx = sin x + C

If +C is missing on an indefinite integral, it is wrong — graders deduct.
NEVER write +C
Definite integrals — bounds are given.

∫₀² x² dx = [x³/3]₀² = 8/3 − 0 = 8/3

The +C cancels when you subtract F(a) from F(b), so it's never in the final answer.
❌ Single most penalized mistake on FRQs: Omitting +C on an indefinite integral. Build the habit — every indefinite integral answer ends with + C
Finding a Specific Antiderivative Using an Initial Condition

When you're given a point (initial condition), you can solve for C and get the particular antiderivative — the one specific function in the family.

Method
Given: f′(x) = 2x and f(3) = 10. Find f(x).

Step 1: Integrate → f(x) = x² + C
Step 2: Apply initial condition → f(3) = 9 + C = 10 → C = 1
Step 3: Particular solution → f(x) = x² + 1
6.3

Basic Antiderivative Rules

Power Rule for Integrals
∫ xn dx = xn+1n+1 + C     (n ≠ −1)
Add 1 to the exponent, then divide by the new exponent. The reverse of multiplying by n and subtracting 1.
Examples
∫ x⁵ dx = x⁶/6 + C  |  ∫ x−2 dx = x−1/(−1) + C = −1/x + C
∫ x1/2 dx = x3/2/(3/2) + C = (2/3)x3/2 + C
∫ √x dx = (2/3)x3/2 + C  |  ∫ 1 dx = x + C
❌ Cannot use when n = −1. ∫ x−1 dx = ∫ 1/x dx = ln|x| + C, not x⁰/0 (division by zero). This is a separate rule.
Constant & Constant Multiple Rules
∫ k dx = kx + C      ∫ k·f(x) dx = k · ∫ f(x) dx
Constants factor out of integrals. The integral of a constant k is kx, not just k.
Sum / Difference Rule
∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx
Integrate term by term. Just like differentiation.
Exponential & Log Rules
∫ ex dx = ex + C
∫ 1x dx = ln|x| + C
∫ ax dx = axln a + C
e^x is its own antiderivative. 1/x integrates to ln|x| — the absolute value matters when x could be negative.
Practice · Basic Antiderivative Rules
Problem
Evaluate: ∫ (4x³ − 3x² + 5√x + 2) dx
1
Rewrite everything as powers of x
= ∫ (4x³ − 3x−2 + 5x1/2 + 2) dx
→ Same rule as differentiation — convert roots and fractions to exponent form before applying the power rule.
2
Integrate term by term using power rule
4x³ → 4 · x⁴4 = x⁴
−3x−2 → −3 · x−1−1 = 3x−1
5x1/2 → 5 · x3/23/2 = 5 · 23x3/2 = 103x3/2
2 → 2x
3
Assemble with +C, convert notation
= x⁴ + 3x + 103x3/2 + 2x + C
→ 3x⁻¹ = 3/x. The +C is mandatory — this is an indefinite integral.
Problem
Evaluate: ∫ (6x² + 4x³ − 3e^x) dx
Step 1 — Rewrite fractions as negative exponents
Step 2 — Apply power rule to each polynomial term. What do 6x² and 4x⁻³ become?
Step 3 — Integrate −3e^x and assemble the full answer with +C
4/x³ = 4x⁻³

∫ 6x² dx = 2x³
∫ 4x⁻³ dx = 4 · x⁻²/(−2) = −2x⁻² = −2/x²
∫ −3e^x dx = −3e^x

Answer: 2x³ − 2/x² − 3e^x + C
Problem
Evaluate: ∫ (5x⁴ − 2x + 7e^x − 4x1/3) dx
∫ 5x⁴ dx = x⁵
∫ −2/x dx = −2 ln|x|
∫ 7e^x dx = 7e^x
∫ −4x1/3 dx = −4 · x4/3/(4/3) = −3x4/3

Answer: x⁵ − 2ln|x| + 7e^x − 3x4/3 + C
6.4

Trig Antiderivatives

Full table + memory system
The Full Table — All 6 Functions
∫ sin x dx
= −cos x + C
sin integrates to −cos (gets negative)
∫ cos x dx
= sin x + C
cos integrates to +sin (no negative)
∫ sec²x dx
= tan x + C
sec² → tan (undo the derivative of tan)
∫ csc²x dx
= −cot x + C
csc² → −cot (negative for co-function)
∫ sec x tan x dx
= sec x + C
sec·tan → sec (undo d/dx[sec x])
∫ csc x cot x dx
= −csc x + C
csc·cot → −csc (negative for co-)
💡 Memory system — read the derivative table backwards: Every trig antiderivative is exactly the reverse of the corresponding trig derivative. If d/dx[sin x] = cos x, then ∫ cos x dx = sin x. If d/dx[−cos x] = sin x, then ∫ sin x dx = −cos x. You already know these — just read the derivative table in reverse.
❌ Most common trig antiderivative error: Writing ∫ sin x dx = +cos x (missing the negative). The negative comes from reversing d/dx[cos x] = −sin x. When you flip that: ∫ sin x dx = −cos x + C.
Practice · Trig Antiderivatives
Problem
Evaluate: ∫ (3 sin x − 5 sec²x + 2 cos x) dx
1
Integrate term by term
∫ 3 sin x dx = 3 · (−cos x) = −3 cos x
∫ −5 sec²x dx = −5 · (tan x) = −5 tan x
∫ 2 cos x dx = 2 · (sin x) = 2 sin x
→ Each term uses its trig antiderivative. Scalar multiples factor out and survive.
2
Assemble with +C
= −3 cos x − 5 tan x + 2 sin x + C
Problem
Evaluate: ∫ (4 cos x + 2 csc²x − sec x tan x) dx
What is the antiderivative of each term separately?
Assemble the full answer with +C
∫ 4 cos x dx = 4 sin x
∫ 2 csc²x dx = −2 cot x
∫ −sec x tan x dx = −sec x

Answer: 4 sin x − 2 cot x − sec x + C
Problem
Evaluate: ∫ (6 sin x − 4 csc x cot x + 3 sec²x) dx
∫ 6 sin x dx = −6 cos x
∫ −4 csc x cot x dx = 4 csc x  (since ∫ csc x cot x dx = −csc x, times −4 gives +4 csc x)
∫ 3 sec²x dx = 3 tan x

Answer: −6 cos x + 4 csc x + 3 tan x + C
6.5

Indefinite vs Definite Integrals

The Difference
Indefinite Integral
∫ f(x) dx

No bounds. Answer is a function — the family of all antiderivatives.

Result: F(x) + C

Always ends with + C.
Definite Integral
∫ab f(x) dx

Has bounds a and b. Answer is a number — the net area under f from a to b.

Result: F(b) − F(a)

Never ends with + C.
Evaluating Definite Integrals — Step by Step
  1. Find the antiderivative F(x).→ Do not write +C here — it cancels anyway and clutters the work.
  2. Write [F(x)]ab using bracket notation.→ This notation means "evaluate F from a to b."
  3. Compute F(b) − F(a).→ Substitute the upper bound first, then subtract the lower bound value.
  4. Simplify to a single number.
Fully Worked Example
∫13 (x² + 2) dx

= [x³3 + 2x]13

= (273 + 6) − (13 + 2)

= (9 + 6) − (13 + 2)

= 15 − 73 = 383
Properties of Definite Integrals — Know These for FRQs
PropertyRuleWhat It Means
Flip bounds∫ab f = −∫ba fSwapping bounds negates the integral
Same bounds∫aa f = 0No width → no area
Split interval∫ab f = ∫ac f + ∫cb fCan break any interval at any point c
Scalar multiple∫ab k·f = k·∫ab fConstants factor out
Sum/Difference∫ab [f±g] = ∫f ± ∫gSplit across addition and subtraction
Practice · Definite Integrals
Problem
Evaluate: ∫0π/2 (cos x + 2) dx
1
Find the antiderivative (no +C for definite integrals)
∫ (cos x + 2) dx = sin x + 2x
2
Write bracket notation
[sin x + 2x]0π/2
3
Evaluate at upper bound (π/2), then lower bound (0)
F(π/2) = sin(π/2) + 2(π/2) = 1 + π
F(0) = sin(0) + 2(0) = 0
4
Subtract: F(b) − F(a)
(1 + π) − 0 = 1 + π
Problem
Evaluate: ∫14 (3x + 2x) dx
Step 1 — Find the antiderivative of each term
Step 2 — Write the antiderivative in bracket notation from 1 to 4
Step 3 — Evaluate at x = 4, then x = 1. Subtract.
∫ 3/x dx = 3 ln|x|  |  ∫ 2x dx = x²
Antiderivative: 3 ln|x| + x²

F(4) = 3 ln 4 + 16
F(1) = 3 ln 1 + 1 = 0 + 1 = 1

Answer: 3 ln 4 + 16 − 1 = 3 ln 4 + 15 ≈ 19.16
Problem
Evaluate: ∫0π sin x dx   — then interpret the result geometrically.
∫ sin x dx = −cos x
[−cos x]0π = (−cos π) − (−cos 0) = (−(−1)) − (−1) = 1 + 1 = 2

Geometric meaning: The area under one arch of the sine curve from 0 to π equals exactly 2 square units. Since sin x ≥ 0 on [0, π], this is purely area — no negative cancellation.
6.6

Step-by-Step Integral Solving

Decision process for any integral
The Decision Tree — What to Try First
  1. Can I rewrite the integrand?→ Expand products, split fractions, convert roots to exponents. Many integrals simplify before any rule is needed.
  2. Do I recognize a basic rule?→ Power rule, trig, e^x, 1/x — check the reference table first.
  3. Is there a composite function with its inner derivative present?→ If yes → u-substitution (Section 07). The inner function becomes u, its derivative becomes du.
  4. Is it a product of two unrelated functions?→ Integration by parts (not tested on AB, but good to know the pattern fails here).
Common Rewriting Moves Before Integrating
Expand before integrating
∫ x(x² + 3) dx → expand first → ∫ (x³ + 3x) dx = x⁴/4 + 3x²/2 + C

∫ (x+1)² dx → expand → ∫ (x²+2x+1) dx = x³/3 + x² + x + C
Split a fraction before integrating
∫ x³ + 5xx dx → split → ∫ (x² + 5) dx = x³/3 + 5x + C

∫ 3x² − 2xx² dx → split → ∫ (3 − 2x−1) dx = 3x − 2 ln|x| + C
⚠️ You can only split fractions where the denominator is a single term. ∫ 1/(x²+1) dx cannot be split this way — that requires a different technique. Only split when the denominator divides into every numerator term.
Practice · Rewrite & Integrate
Problem
Evaluate: ∫ x⁴ − 3x² + 2x² dx
1
Split the fraction — divide each numerator term by x²
= ∫ (x⁴x² − 3x²x² + 2x²) dx = ∫ (x² − 3 + 2x−2) dx
→ Each term is divided separately. The denominator must be a monomial for this to work.
2
Integrate term by term
x² → x³/3
−3 → −3x
2x−2 → 2 · x−1/(−1) = −2/x
3
Write final answer with +C
x³3 − 3x − 2x + C
Problem
Evaluate: ∫ x(3x − 2)² dx
Step 1 — Expand (3x−2)² first
Step 2 — Multiply by x to get the full integrand
Step 3 — Integrate term by term with +C
(3x−2)² = 9x² − 12x + 4
x(9x² − 12x + 4) = 9x³ − 12x² + 4x

∫ (9x³ − 12x² + 4x) dx
= 9x⁴/4 − 4x³ + 2x²

Answer: (9/4)x⁴ − 4x³ + 2x² + C
Problem
Evaluate: ∫14 √x (x + 2)1 dx
Expand: √x(x+2) = x3/2 + 2x1/2

∫ (x3/2 + 2x1/2) dx = x5/2/(5/2) + 2x3/2/(3/2)
= (2/5)x5/2 + (4/3)x3/2

Evaluate 1 to 4:
F(4) = (2/5)(32) + (4/3)(8) = 64/5 + 32/3 = 192/15 + 160/15 = 352/15
F(1) = 2/5 + 4/3 = 6/15 + 20/15 = 26/15

Answer: 352/15 − 26/15 = 326/15 ≈ 21.73
